# Task map

Resolve the matching package root using [SKILL.md](../SKILL.md). Start with `components/CATALOG.md` for component selection and contract links. Use [API_MAP.md](API_MAP.md) for named exports, props, and implementation paths. Package-root paths below are code references. Availability follows the actual installed artifact, including when a working tree and a registry release share a version number.

## Find a component

The catalog and showcase use the following seven categories for discovery. Each catalog row describes the Rhine contract. For coverage, verify the value in `components/index.ts` and inspect its contract before adding an export.

| Catalog category | Typical task | Contract and source showcase |
| --- | --- | --- |
| General (通用) | Action vs. link, typography and numbers, icon naming, responsive action groups, logo | `docs/BUTTON_ACTIONS.md`, `docs/RESPONSIVE_ACTIONS.md`, `components/TYPOGRAPHY.md`, and the logo section of `components/README.md`. See `#button-actions`, `#responsive-actions`, `#typography`, and `#brand`. |
| Layout (布局) | Spacing, grouping, surfaces, application shell, flexible or grid layout | `components/SPACING.md`, `docs/APPLICATION_COMPONENTS.md`, `components/PROVIDED_COMPONENTS.md`. Choose `Grid` for minimum-width columns and `Columns` with `Column` for explicit 24-column spans. See `#spacing` and `#app-shell`. |
| Navigation (导航) | App destinations, command menu, breadcrumbs, steps, tabs, pagination or page anchors | `docs/INTERACTION_PATTERNS.md`, `docs/SUMMARY_TABS.md`, `docs/APPLICATION_COMPONENTS.md`, `components/PROVIDED_COMPONENTS.md`. `NavigationMenu` supports native links, `Menu` presents commands, and `Tabs` separates width, item distribution, and header actions. See `#navigation` and `#summary-tabs`. |
| Data entry (数据录入) | Inputs, selection, lookup, validation, date ranges and local files | `components/COMMON_COMPONENTS.md`, `docs/APPLICATION_COMPONENTS.md`, `docs/REMOTE_PAGINATION.md`, `components/PROVIDED_COMPONENTS.md`. `Select` is native single-choice, `Combobox` supports candidate lookup, and `RemoteMultiSelect` accepts host-managed query and pagination state. See `#advanced-forms` and `#form-integration`. |
| Data display (数据展示) | Tables, read-only facts, metrics, timeline, images, lists and trees | `components/COMMON_COMPONENTS.md`, `docs/APPLICATION_COMPONENTS.md`, `docs/METRIC_COMPARISON.md`, `docs/TIMELINE_COMPOSITION.md`, `components/PROVIDED_COMPONENTS.md`. `DataTable` and `Pagination` consume host state. `VirtualList` windows equal-height rows; use stable identity for editable rows. See `#advanced-data`, `#metric-comparison`, and `#media`. |
| Feedback (反馈) | Progress, loading, completion, inline notices and modal confirmation | `components/README.md`, `docs/FLOATING_OVERLAYS.md`, `docs/BUTTON_ACTIONS.md`, `components/PROVIDED_COMPONENTS.md`. The host determines outcomes and places `Message` or `Notification`; `Toast` has its own lifetime. Use `ConfirmDialog` for asynchronous confirmation with busy or failure handling and `Popconfirm` for a local synchronous intent. See `#feedback` and `#overlays`. |
| Other (其他) | Theme and local density, sticky content, named regions, decoration and helpers | `docs/THEMING.md`, `docs/THEME_PICKER.md`, `components/PROVIDED_COMPONENTS.md`. Import theme APIs through `@linhey/rhine-design/theme`; `ConfigProvider` supplies local density. See `#theme-picker`. |

## Find a composition or specialized contract

The source showcase in `preview/` demonstrates these combinations and interaction states. Use the contract and the installed artifact when integrating them into a host. The host supplies product data, permissions, requests, and persistence.

| --- | --- | --- |

Unpublished #224–#229. |
| Management glyphs and desktop platform marks | `docs/ICONS.md`, `docs/PLATFORM_MARKS.md` | `#icon`; use same-source iconNames, distinguish actions from licensed platform identity. Unpublished #219/#220. |
