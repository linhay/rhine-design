# 动作语义与按钮尺寸（#46，0.11.2）

variant表达操作层级及后果，尺寸表达场景强调程度。动作名和必要后果必须用文字说明，不只靠颜色。库不根据“退出”“删除”等字符串自动选色，不增加业务按钮组件。

| 动作 | 推荐 | 后果与确认规则 |
| --- | --- | --- |
| 保存、提交、继续等当前主任务 | primary | 同一区域通常一个主操作；输入/后果校验由宿主处理 |
| 导航、详情、更多 | secondary；低频轻量入口可quiet | 有明确点击边界时优先secondary，跳转仍用链接语义 |
| 取消、返回 | secondary或quiet | 与primary主操作区分；会丢失草稿时说明具体后果并按需确认 |
| 退出登录 | 独立会话设置区可primary＋large；与其他主任务并列时secondary | 可重新登录，默认不视为不可逆删除，不因强调而改danger，不强制确认；未保存草稿或持续任务受影响时明确后果并按需确认 |
| 断开可重新连接的连接 | secondary；本节唯一主任务可primary | 说明是否中断当前工作；仅有不可恢复损失时升级危险层级 |
| 停止任务 | 通常secondary | 可以重启/保留结果时保持中性；会永久丢弃工作时danger并说明后果 |
| 重置 | secondary | 预览或可恢复重置保持中性；清空不可恢复配置时danger和明确确认 |
| 可恢复移除 | secondary | 提供撤销/恢复路径及期限；不要仅因“移除”自动染红 |
| 不可逆删除 | danger | 清楚写删除对象、影响和不可恢复性，使用ConfirmDialog等明确确认；只在服务器确认后反馈成功 |

反例：只为醒目把退出登录统一设danger；看到danger就机械新增确认；所有按钮都primary；用颜色替代“不可恢复”的文字。真实展台 `#button-actions` 并排比较退出/断开/删除，全部使用合成操作，不改变真实会话或数据。

## 标准与大尺寸

`Button.size?: 'standard' | 'large'` 默认standard，保留现有行为。此能力不在冻结0.11.0制品中。原有variant、busy、disabled、contentAlign及原生button属性不变。

| 尺寸 | 字号/行高/字重 | 最小高度 | 上下/左右内距 | 场景 |
| --- | --- | --- | --- | --- |
| standard | 14/22/label | 44px | 10px/16px | 表单、卡片动作和常规工具栏 |
| large | 16/24/label | 52px | 12px/24px | 独立设置动作、需要更醒目和易点击的主入口 |

最小高度不是固定高度：主题边框可能自然增高，长标签按可用宽度换行，字号不缩小、内容不裁切。默认按内容宽度；独立窄表单需要铺满时在Button原生style设置width:'100%'，不要把一组不相关动作全拉满。容器约束可用宽度，按钮max-width为100%，不会以全局固定宽度绑定业务场景。

busy沿用原内容占位与spinner，尺寸不跳变，保留焦点且拒绝重复点击；aria-disabled与事件防重同时生效。不同动作可用不同variant，但同组相同层级尺寸应保持配对。大尺寸也使用原主题hover/active/focus/disabled规则，不额外改颜色、圆角或动效；系统和手动减少动态沿用库规则。

本轮可读性复核修正战术主题danger：深色文字沿用主题accent-ink，默认警戒红底，hover使用较深红底；默认/hover文字对比均高于4.5:1。其他危险状态语义和主题配色不变。

独立获取目录/数据使用 secondary 的明确边界；标题附属轻量模板切换可用 quiet。字段标题动作插槽不改变动作层级，不因同处设置页而一律 quiet。

## 容器自适应动作

空间不足时，完整文字+图标→整组图标→竖点菜单逐级收纳，保持宿主顺序、权限、busy/disabled和至少44px目标；按实际容器与内容测量，不仅按viewport。更新日期等元信息放内容区。最小公开组合与焦点连续性见[ResponsiveActions](RESPONSIVE_ACTIONS.md)。
