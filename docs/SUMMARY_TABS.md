# 带摘要的页签 · Summary Tabs

版本边界：自 0.11.0 提供；npm 0.10.0 不包含这些字段，见[版本记录](../CHANGELOG.md#01102026-10-27)。实现使用现有 `Tabs` 的 `description` / `status`，不新增另一套组件。规范、组件和展台必须一起验收；消费方不得用后代选择器另改间距。

## 适用范围与结构

同一任务中切换少量独立对象，同时需要知道每个对象当前身份和状态，例如不同客户端、工作区或运行环境。建议2–3项；大量对象优先简洁Tabs或导航列表，完整身份留在内容区，不将大量摘要挤进一排。

每个页签只有两组信息：第一组为名称及一个只读状态；第二组为身份摘要。状态即使未选中也保持可见，不暗示“选中才运行”。详细说明、路径、刷新按钮、停止同步等操作放在面板或操作栏，不能嵌套在Tab按钮中。

```text
┌── 命中区域：上12 / 下12，水平0 ──────────┐
│ 名称  ← 8 →  状态                       │ 14/22；状态复用Badge
│              ↓ 4                       │
│ 类型 · 当前身份                         │ 12/18
└────────────── 2px选中线 ────────────────┘
                 ↓ 24
面板第一组内容
```

图示尺寸是CSS像素；文字按行盒对齐，不能以中文字形的上下空白反推padding。

## 间距与排版

| 部位 | 值 / token | 说明 |
| --- | --- | --- |
| 名称 | 14/22，600；body / leading-body / weight-heading | 左对齐；不是页面标题 |
| 摘要 | 12/18，400；caption / leading-caption / weight-regular | muted语义色；不得继承名称加粗 |
| 状态 | 复用Badge契约 | 当前Badge为12/20、上下2px内距；各主题保留自己的边框、字重和内距，不在Tabs重画 |
| 名称到状态 | 8，space-2 | 同一flex行；空间不足状态自然换行 |
| 第一组到摘要 | 4，space-1 | 紧密身份组合；不同于普通卡片标题/说明的8px配方 |
| 命中区上下内距 | 各12，space-3 | 水平0；首组与末组分别到上下边界 |
| 相邻页签间距 | 16，space-4 | 不再叠加水平padding |
| 页签分隔线到面板内容 | 24，space-6 | 由Tabs面板负责；调用方首项不得再加顶部margin |
| 命中区域 | 最小高度44，自然增高 | 默认莱茵单行名称/状态、单行摘要70px（24+4+18+12×2）；Badge或文字换行可增高 |
| 底部线 | 普通1px，选中2px | 选中线覆盖该页签命中区宽度；状态徽标不替代选中线 |

`layout="content"`（新默认）按内容宽度靠左排列，页签栏收缩到内容总宽度并受max-width约束；`layout="fill"`显式均分可用宽度，两种布局均从顶部对齐。status/description只决定文字结构，不决定铺满；第一项与面板正文左缘对齐。容器保持至少必要的焦点外延空间，不加阴影、整块选中底色、额外卡片边框或圆角胶囊。

## 状态、主题与动效

| 状态 | 外观 / 行为 |
| --- | --- |
| 未选中 | 名称muted，摘要muted；状态仍用其真实语义色 |
| 选中 | 名称ink与2px指示线；摘要不加粗、不变为成功色 |
| 悬停 | 可用页签名称变ink；无抬升、阴影或位移 |
| 键盘焦点 | 沿用库2px焦点环与3px偏移，和选中线分开 |
| 禁用 | 沿用库禁用透明度；不能点击，方向键跳过；不是错误状态的替代品 |
| 加载 | 保留已知身份，状态写“读取中”；未知身份写“尚未读取”，不编造账号 |
| 错误 / 未知 | 明确文字徽标；保留可信旧值或显示未匹配，详情在面板 |

状态是对象事实，选中是浏览位置；两者不能互相驱动。三主题只通过现有语义tokens、Badge和主题规则变化；橙趣等主题Badge较高时自然抬高整行，不能压缩字高去维持70px。状态外层使用inline-flex，消除额外的行内基线空白。

选中线与面板沿用180ms的库动效，状态文字即时更新，不因标签变化循环动画；系统或手动减少动态时立即呈现。动画、状态与请求成功互不代替。

## 窄窗与可访问性

- 320px局部容器、400/520/880视口和200%缩放保持字号及间距；名称、状态和摘要自然换行，页签等高顶对齐，不固定高度、不裁剪身份，不使用省略号隐藏唯一辨识信息。
- `label`始终是稳定可访问名称；`description`与`status`通过`aria-describedby`关联。状态更新不改`value`、焦点或当前页签。
- 左右方向键循环，Home/End到首末可用项；跳过禁用项。隐藏面板保留挂载但退出可访问树。新增摘要不改变这些行为。
- 状态仅允许纯文本或只读Badge，不允许按钮、链接、菜单、Switch、live region；异步结果由面板反馈，避免多个Tab反复播报。
- 首次读取、错误及后台状态变化均不自动切页；宿主保存每个对象的状态，不把当前对象复制给其他页签。

## 接入与展台

```tsx
<Tabs label="工作区" value={selected} onValueChange={setSelected} items={[
  { value: 'primary', label: '主工作区', description: '研发 · 研究项目',
    status: <Badge tone="success">同步中</Badge>, content: <PrimaryPanel /> },
  { value: 'team', label: '协作工作区', description: '协作 · 设计项目',
    status: <Badge>已停止</Badge>, content: <TeamPanel /> },
]} />
```

独立展台 `/#summary-tabs` 提供局部320/520/自适应宽度、正常/加载/错误/禁用/长文本、尺寸说明和可编辑面板草稿。保留 `/#selection` 普通Tabs作对照；两个变体不能共用临时业务CSS。包内入口见[组件契约](../components/README.md)，间距含义见[间距规范](../components/SPACING.md)。

验收同时检查计算样式与实际像素：12/8/4/16/24、名称14/22/600、摘要12/18/400；三主题长文本、键盘、禁用跳过、焦点保留、隐藏面板、状态变化、系统/手动减少动态。局部无横向溢出不替代视觉检查。正式消费需固定包含此能力的版本或提交；本地候选展台不代表能力已经发布。

## 单行摘要与显式布局（#41，自 0.11.2）

身份已在内容区可读时，只传label和只读status，不传description，即名称＋短状态的单行组合。`layout="content" | "fill"`与摘要存在与否独立，默认content；0.11.0摘要曾隐式铺满，升级后需维持原展示时显式传fill。文字过长自然换行，页签组可换行，不缩小字号、不裁剪，内容面板始终使用可用宽度。选中下划线跟随对应按钮，content下就是该页签内容宽度。

真实展台 `#summary-tabs` 可切换单/双行与两种布局，`#compact-selection` 展示单行摘要与完整身份区。异步身份/状态更新不改变value或焦点，方向/Home/End及隐藏面板保留规则不变。


## 满栏靠左（#76，未发布）

表单或设置区的内容页签可优先采用整栏铺满、文字与指示线按内容靠左的组合。用户说“模块铺满”时，先判断需要铺满的是栏，不能自动将每个选项等分。此偏好不强制所有 Tabs 等分，也不改变现有默认。

| 组合 | 栏宽与分隔线 | 选项分配 | 文字对齐 | 选中指示线 |
| --- | --- | --- | --- | --- |
| `layout="content"`（默认） | 随内容收缩，上限100% | 内容宽度，靠左 | 保持既有文字规则 | 当前按钮宽度 |
| `layout="content" fullWidth` | 正文可用宽度100% | 内容宽度，靠左 | 行内起点对齐，换行也靠左 | 当前按钮宽度，不拉长到半栏 |
| `layout="fill"` | 正文可用宽度100% | 等分 | 简洁标签居中；带摘要仍按原规则靠左 | 当前等分按钮宽度 |

这四个维度需要分别判断，并不意味着每个维度都要增加一个参数。本次只增加 `fullWidth?: boolean`（默认false），和现有 `layout` 组合；fill原本已铺满，传入或省略fullWidth不改变其行为。面板始终使用可用宽度。过长标签受容器宽度约束后自然换行，按钮可以换行，不裁剪文字、不缩字号。禁用项保持可见但不可激活，方向键跳过它；其余键盘与面板语义保持原契约。

```tsx
<Tabs label="权限范围" layout="content" fullWidth
  value={scope} onValueChange={setScope}
  items={[
    { value: 'current', label: '当前对象', content: <CurrentScope /> },
    { value: 'custom', label: '自定义范围', content: <CustomScope /> },
  ]}
/>
```

真实展台 `/#summary-tabs` 同时展示三种布局，宽屏并排、窄屏堆叠；支持长标签、禁用项、受控联动和各面板独立草稿。三主题×400/520/880×100/200% CSS zoom量测栏与面板同宽、首项起点、内容按钮与下划线宽度，并验证键盘、隐藏面板及减少动态。CSS zoom不等同原生网页缩放；iframe内缩放不证明外壳缩放。

**npm 0.11.3 不含 fullWidth。** 消费方须使用明确包含此能力的固定提交制品；版本号相同也不能视为registry正式包。验证完成后以公开属性替换临时tablist宽度覆盖，并保留manifest、lockfile、制品摘要与消费验收。源码合并、Pages更新、npm发布、消费迁移分别记录；详见[本次验收](TABS_LAYOUT_VERIFICATION.md)。
