## 1. 目标与范围

用户在打开应用后应能立即回答三个问题：当前 Codex 使用什么连接方式？OAuth 自动同步是否正在运行？今天产生了多少已采集用量？

- 清晰可信：状态以服务返回为准，操作成功前不提前显示「已生效」。
- 安静精密：暖白、墨绿黑、细分隔线、等宽数字；装饰服务于层级。
- 紧凑可读：适配现有 520×640 默认窗口与 400×540 最小窗口；大窗口承载更多并列内容，小窗口允许自然纵向滚动。
- 行为连续：保持现有授权、同步、API-Key 切换、用量与后台驻留语义。

消融决策：移除重型侧栏（只有两个主功能）；不新增仪表盘首页（避免重复状态）；不引入字体网络依赖（系统字体足够）；不将轨道动画放进工作区（无助任务判断）；不新增同步开关、日志页、路径编辑或周期设置（现有选择语义可完成任务）。这些删减不影响上述目标。

## 3. 信息架构

```text

├─ 未登录：ToD-AI → 浏览器登录 / 等待 / 超时 / 恢复失败
└─ 已登录
   ├─ 凭证同步
   │  ├─ 当前本地配置方式与同步状态
   │  ├─ OAuth 账号 / API-Key 浏览面板
   │  ├─ 账号竖卡或 Key 列表

   │  ├─ 请求 / Token / 预估费用 / 平均耗时
   │  ├─ 模型分布（Token / 请求数）
```

### 4.3 几何与布局

- 间距序列 4/8/12/16/24/32/48px。窗口内容边距 24px；宽度低于 480 时 20px。
- 主内容最大 880px；账号卡最小 220px、间距 16px，按实际容器宽度排 1/2/3 列。520 宽窗口：两列；400 宽：一列。详情常显，状态区预留至少两行。
- 卡片圆角 4px，按钮 3px；保留原生窗口圆角，不在 WebView 内再画一层假窗口。
- 控件最小高度 40px，主要操作 44px；移动预览/触屏按至少 44px 目标校验。
- 1px 分隔线；选中卡以 2px 深绿边界与「已选择」文字共同表达。焦点环 2px，偏移 3px。
- 400px 原生窗口为最小验收尺寸；375px 是浏览器额外鲁棒性检查，不宣称新增移动 App。
- 四项指标保持同排；窄窗数字缩到 20px，说明允许换行。请求明细低于 480px 转为逐条记录布局，保留全部五类字段及分页，不以超小字塞表格。
- 100% 与 200% 字体缩放下允许纵向增长、重排；不固定卡片高度、不裁掉报错和主要操作。

## 6. 关键状态与文案

### 6.1 登录

| 状态 | 主文案 | 操作 |
| --- | --- | --- |
| 未登录 | 连接你的工作空间 | 在浏览器中登录 |
| 等待 | 等待浏览器授权 / 请在浏览器完成授权，5 分钟内有效 | 重新打开浏览器、取消登录 |
| 超时 | 本次授权已超时 | 重新登录 |
| 网络异常 | 暂时无法连接网关，已保留登录凭据 | 重试 |
| 凭据库不可用 | 本次登录仅在应用运行期间保留 | 保留当前会话，不假装持久化成功 |

等待态不自行定时模拟成功；取消使旧回调失效。无需新增准确秒级倒计时，现有 DTO 无到期时间字段。

### 6.2 OAuth 与 API-Key

| 条件 | 呈现与后续 |
| --- | --- |
| 初始未管理 | 请选择连接方式；无卡片选中，不推断已连接 |
| 开始同步 | 正在检查并应用凭证；不提前显示运行中 |
| 成功运行 | OAuth · 自动同步已开启；最近检查、最近写入分开 |
| 取消选择 | 自动同步已停止；本地配置与凭证保留 |
| 配置仍为 OAuth，但 phase=idle | 「本地配置：OAuth / 自动同步未开启」，不能显示断开或运行中 |
| 切换 API-Key | 按钮显示切换中；完成后显示本地配置已切换，OAuth 停止 |
| Key 模型列表失败 | 暂时无法读取模型；不猜测支持范围、不阻止可用 Key 显示 |
| 本地配置被其他程序改动 | 同步已停止；检查后重新选择账号。不是自动覆盖 |
| profile 冲突 / 配置不可解析 | 未覆盖配置；明确修复指引，无「已切换」提示 |
| 恢复失败 | 持续醒目提示，从已有备份恢复两份文件；不自动消失 |
| 订阅 401/403 | 当前账号不可同步；保留网关登录，说明重新选择/检查授权 |
| 登录目录 401 | 回到重新登录流程，不与订阅拒绝混淆 |

当前 `SyncView` 只有 idle/starting/running/error；「外部修改」「权限拒绝」等通过 error 细化，不增加平行的前端状态真源。UI 操作 pending 可在本地保存，但最终选中、模式和结果服从 Rust 返回。停止按钮/取消选择成功前不能宣称停止完成。

本轮重构需修正的一处语义：现在部分 UI 文案只按 `mode=oauth` 表述「当前使用 OAuth」，而 `phase=idle` 可能仍保留该 mode。新版应同时读 mode/phase，区分本地配置与自动同步；浏览面板不代表实际请求路径，已打开 Codex 会话可能还需重开。

### 6.3 今日用量

- 日期统一 Asia/Shanghai，并标出「今日 / 上海」；展示的是当前登录人员的已采集用量，不是所选 OAuth 账号余额。
- 首次加载使用稳定骨架或读取提示；刷新时保留旧数据并显示正在更新。
- 刷新失败保留旧数据，明确「以下为上次读取结果」；未读到数据不显示 0。
- 无请求：显示「今日暂无已采集用量」；没有计价请求时费用显示「—」，不是 $0.00。
- `coverage.status != complete`：指标上方显示采集可能不完整。未计价请求数量独立说明。
- 请求数 = 总请求数，失败数是其子集；图表仅显示最多六个模型，不把条形相对最大值解释成占比。
- 手动刷新回第一页；分页由服务端提供。以后新增搜索/筛选必须走接口，不能加载全量再本地筛。

### 6.4 驻留与应用更新

关窗只是隐藏；重新打开读取真实状态，不重新发起一轮同步。退出登录和显式退出取消任务但保留本地已写文件。应用安装时显示「正在安装更新，请重启后再切换账号」，UI 禁用和 Rust 操作锁共同成立。原生托盘状态、窗口行为与实际安装均需要专项验收。

## 7. 图标、装饰和动效

用户已选定三角构架Logo，组件层使用唯一SVG母版和可选240ms单次归位；正式安装图标与托盘资产尚未迁移。登录可展示静态标志，工作区不循环播放装饰动画。

环形/轴线仅用于登录的轻量背景或文档封面，不穿过正文。无扫描线、故障抖动、闪烁状态、无意义条码与伪仪器数值。悬停 120ms，按下 80ms，面板切换 180ms，提示与展开 200ms，进度更新 240ms；不移动卡片来表现选择。`prefers-reduced-motion` 关闭非必要动画。组件逐项动效、收起规则、快速反向、循环状态和降级边界见[动效规范](../components/README.md#动效规范)。

### 7.1 Transitions.dev UX 与动效参考

用户指定[Transitions.dev](https://transitions.dev/)为参考。已补入[UX与动效细则](../components/MOTION.md)：借鉴主动播放/重播、清晰的前后状态、锚点方向与加载衔接；参数继续使用ToD-AI tokens。逐项列出40组件中的已实现能力，以及菜单方向、内容淡入、结果反馈和展台对照的待实现设计候选。

`/#motion`已提供10组播放/重播/复位示例，以及原速/4倍慢放、逐例减少动态。方向展开、内容淡入和结果反馈已作为展台候选实现，通用默认与App仍未采用这些新配方。保持文字、指标和操作目标稳定，减少动态不影响功能。

## 8. 重构顺序与验收

1. **视觉基础**：引入 `tokens.css` 的语义变量，整理 app/styles.css，统一字体、间距、按钮与焦点；不改变 IPC。
2. **登录与外壳**：BrowserLogin、Workspace、底部身份/更新条；保留原生窗口控件和双 Tab。
3. **凭证页**：拆分展示组件 AccountCard、KeyCard、ConnectionStatus；保留现有数据源与操作边界，避免为外观引入状态框架。
4. **用量页**：指标、图表、明细、空/错/不完整状态；沿用 todayUsage(page)。
5. **原生与发布前验收**：浏览器预览通过后，分别验证 macOS/Windows 原生环境；发布走既有发布流程。

| 验收维度 | 必验情况 |
| --- | --- |
| 布局 | 400×540、520×640、880×760；长名称/邮箱/模型 ID；200% 文字 |
| 键盘 | Tab 顺序、左右切 Tab、Space 选择账号、Enter 操作；清晰 focus |
