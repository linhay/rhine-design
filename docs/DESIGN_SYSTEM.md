# 莱茵设计 · 通用设计规范

本规范是 Rhine Design 的设计基线，覆盖色彩、文字、组件状态、布局和动画，供不同产品复用。配套 React 实现为 @linhey/rhine-design；版本演进见[CHANGELOG](../CHANGELOG.md)，组件契约见[组件入口](../components/README.md)。

## 1. 设计语言

暖白背景、苔绿结构、墨色文字、细线分隔和少量橙色定位形成安静、精密的秩序。三角几何用于品牌结构，装饰不穿过正文、不遮挡操作，不制造虚假仪表状态。参考作品仅提供风格方向；标志、参数和实现是独立设计，不构成官方VI。

## 2. 通用原则

- 状态真实：未知不显示为零，操作完成前不宣称成功，刷新失败可保留旧数据并标明时效。
- 可读优先：系统字体、清晰层级、自然换行；200%缩放不丢失文字或操作。
- 交互连续：忙碌保留焦点，浮层有明确退出与焦点归还；快速重播和打断不留下透明遮挡。
- 组件优先：先更新规范、组件与真实展台，再由消费项目选择版本；业务流程不进入通用组件。
- 动效克制：反馈服务于状态理解，就绪不等待装饰，减少动态不削弱功能。

密集任务浮层的落地规则：先按用户决策划分常显/按需信息；区域标题、数量和操作集中到导航行；短内容自然撑高、默认单层滚动；可见间距与44px操作范围分别验证。详见[场景与交互规范](INTERACTION_PATTERNS.md#弹窗高度与滚动归属)和[间距组合](../components/SPACING.md#视觉间距与操作范围)，选择即保存仅按其适用边界使用。

### 工作区顶部与页面身份

侧栏已经明确当前页面的平级工作区，顶部默认不再重复“工作空间 / 当前页”面包屑或页面大标题。顶部用于导航展开、当前对象/连接状态与实际操作；正文直接呈现任务内容。保留主内容的可访问名称、一级标题（可用 `rhine-sr-only`）以及导航 `aria-current`，路由变化后仍将焦点移入正文。

移除标题不等于移除操作行：窄屏抽屉、收起侧栏后的恢复入口、刷新和必要状态必须持续可达。没有可见内容的操作容器无需为标题预留额外高度；若承载恢复入口，应按实际可见控件保留。只有存在真实父子资源层级且用户需要返回上级时才使用 Breadcrumbs，不把它作为每个页面必填的装饰。组件本身继续提供该能力。组合与验收见[应用布局契约](APPLICATION_COMPONENTS.md#平级工作区顶部操作区)。

## 3. 视觉变量

公开样式接口统一使用 `rhine-`：主题根 `.rhine-theme`、变量 `--rhine-*`、组件类与关键帧 `rhine-*`、减少动态属性 `data-rhine-motion="reduced"`。消费项目的品牌名称只通过内容与组件参数传入，不进入共享命名空间。

### 3.1 色彩

健康历史使用独立的明亮图形色：`--rhine-health-healthy: #19B88A`、`--rhine-health-recovered: #42B8C8`、`--rhine-health-degraded: #EFA629`、`--rhine-health-failed: #EF6464`、`--rhine-health-unknown: #C5CCD3`。这些颜色只用于健康条和图例，不替换苔绿品牌色或正文/错误文字色；恢复态叠加斜纹，选中时段提供文字与可访问名称。不能把图形色用于小号文字或只凭颜色区分状态。

密集账号列表只常显身份、额度和健康条，日期、粒度、优先级机制等共享说明移至按需入口；未知/不完整/错误仍常显。`StatusTimeline compact`将重复时段说明改为悬停/聚焦浮层，保持44px操作区与键盘浏览，不以健康百分比替代历史证据。

| Token | 值 | 用途 |
| --- | --- | --- |
| `--rhine-bg` | `#F2F1E9` | 窗口底色 |
| `--rhine-surface` | `#FCFCF8` | 卡片、输入、浮层 |
| `--rhine-ink` | `#242B28` | 正文、主按钮 |
| `--rhine-muted` | `#59645D` | 次级文字 |
| `--rhine-line` | `#C5CCC1` | 装饰分隔线，不独立承担控件识别 |
| `--rhine-control` | `#78857B` | 必须可识别的控件边界 |
| `--rhine-selected` | `#E5ECE3` | 选中背景 |
| `--rhine-green` | `#425C4B` | 选中标记、成功文字、焦点环 |
| `--rhine-signal` | `#C65C34` | 少量品牌定位色，不用于小字 |
| `--rhine-warning` | `#8A472C` | 待处理、冲突、覆盖不完整 |
| `--rhine-error` | `#A13E35` | 操作失败、需要恢复 |

本稿测算：正文 / 底色 12.77:1，次级文字 / 底色 5.44:1；品牌橙 / 底色仅 3.72:1，因此只用于非文字标记或符合大字要求的展示文字。重要状态同时有文字。数据未知显示「— / 暂不可用」，不显示 0%，未知进度不画百分比。

### 3.2 字体与密度

完整规则见 [字体与文字规范](../components/TYPOGRAPHY.md)；涵盖9档文字样式、中文混排、数字单位、换行截断、内容语义和动效边界。主流系统对照与待补能力见 [补齐顺序](./DESIGN_SYSTEM_AUDIT.md)。

正文使用系统栈 `-apple-system, BlinkMacSystemFont, Segoe UI, PingFang SC, Microsoft YaHei, sans-serif`；数字使用 `font-variant-numeric: tabular-nums`；路径与编号使用系统等宽栈。首期不下载 Web Font。

| 用途 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 登录标题 | 30 / 38px | 600 |
| 工作区分组标题 | 18 / 26px | 600 |
| 卡片身份 | 16 / 24px | 600 |
| 正文、主要操作 | 14 / 22px | 400–600 |
| 标签、时间、辅助说明 | 12 / 18px | 400–500 |
| 用量关键数字 | 26 / 32px；窄窗 20 / 26px | 600 |

正常视图不出现小于 12px 的业务信息。英文短标签可使用 0.08em 字距；中文不刻意拉大字距。大写英文只作为少量层级辅助。

行高与字号成对消费token；正文14/22、辅助说明12/18、卡片标题16/24、分区标题18/26。多行自然增高，独立正文段落默认12px间距，不用增大行高代替段间距。按钮14/22，点击高度由padding/min-height负责。完整规则及组件例外见[行高规范](../components/TYPOGRAPHY.md#行高段落与控件)。

### 3.3 几何与布局

- 间距序列 4/8/12/16/24/32/48px。默认卡片采用24px内边距、8px标题/说明、16px内容/操作；具体用途、组合与响应式规则见[间距规范](../components/SPACING.md)与展台`#spacing`。窗口内容边距24px；既有窄窗20px边距为布局例外，不新增gap token。
- 展台内容按容器重排；卡片最小宽度按信息密度设定，不能由某个产品窗口宽度推导所有宿主布局。状态区预留文字换行空间。
- 卡片圆角 4px，按钮 3px；保留原生窗口圆角，不在 WebView 内再画一层假窗口。
- 控件最小高度 40px，主要操作 44px；移动预览/触屏按至少 44px 目标校验。
- 1px 分隔线；选中卡以 2px 深绿边界与「已选择」文字共同表达。焦点环 2px，偏移 3px。
- 400/520/880px作为展台验收宽度；消费项目按其最小容器尺寸追加验证。
- 指标与表格按容器重排；数字和说明可换行，必要时表格局部滚动，不以超小字号塞入全部列。
- 100% 与 200% 字体缩放下允许纵向增长、重排；不固定卡片高度、不裁掉报错和主要操作。


## 4. 组件与内容契约

使用[组件契约](../components/README.md)、[常用组合](../components/COMMON_COMPONENTS.md)及[场景与交互选型](./INTERACTION_PATTERNS.md)。0.4.0现有48个组件，npm 0.3.0为40个；接入时核对安装版本的实际导出。表单标签持续可见，提示与错误关联；交互元素使用原生语义或可访问基础。选择、筛选、排序和分页向宿主回传意图，宿主决定数据来源及操作结果。

错误说明发生了什么及可执行的下一步，避免内部堆栈和秘密；成功、警告、未知与空态有文字区分。通知不得依赖颜色或短暂动画才能理解。品牌、实体名、时区和业务单位由宿主定义，具体文案规则见[字体与文字](../components/TYPOGRAPHY.md)。

## 5. 动效与品牌

三角构架以同一SVG母版呈现；默认字标Rhine Design，可配置。几何、颜色和安全间距见[Logo契约](../components/README.md#品牌标志)。完整深色主题仍待补齐，Logo变色不代表全套主题完成。

通用状态过渡以120–240ms为基线，按下80ms；循环只表示实际等待。具体配方、减少动态及候选边界见[动效规范](../components/MOTION.md)。[启动编排](../components/STARTUP.md)展示三块旋转压缩、展开归位以及同一标志收拢的连续性，不是业务初始化门槛。

## 6. 独立迭代与验收

展台浏览采用左右分栏：桌面目录固定在左侧并可独立滚动，右侧一次展示一个章节；窄屏收为顶部目录按钮。目录使用普通链接与`aria-current="page"`，保留深链接、前进/后退，切换后将焦点移到内容区。展开目录按Escape收起并归还焦点。全局动效偏好保持，章节内演示离开后卸载，避免隐藏动画或浮层继续运行。主题根不加transform、contain或裁剪，浮层继续挂载到主题根。此为`preview/GalleryShell.tsx`展台导航模式，未新增公共组件API。

在本仓运行npm run check，新增组件同步契约和默认/禁用/加载/错误/长文本/键盘/动效示例。展台浏览器验收400/520/880宽度、200%缩放、焦点、快速中断、重播和减少动态；独立消费构建验证CSS及SVG资源。

变化记录在CHANGELOG并按语义版本提供迁移说明。消费项目显式选择版本，不随主线自动升级。库验收不依赖某个App迁移完成；真实业务、原生平台与辅助技术由宿主按适用范围补验。剩余能力见[系统对照](DESIGN_SYSTEM_AUDIT.md)。
