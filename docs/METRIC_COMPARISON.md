# 指标比较配方（#159，未发布）

使用 `Metric + Text / Badge + Disclosure` 组合已有能力，不新增 StatCard、统计引擎或 Metric 参数。适用于确有比较任务的概览；无比较需求的指标保持原样。真实合成展台为 `#metric-comparison`，隔离验收入口为 `?fixture=metric-comparison`。

## 常显事实

当前值、单位、比较对象、两侧周期与时区、差值类型及不能比较的原因常显。同组可共享范围说明，例外就近标出。未知、预估、部分采集、陈旧不能藏在 hover 或只用颜色表达；数值立即更新，不滚动计数。完整精确值、公式、来源按需使用键盘可操作的 Disclosure，概览缩写不参与计算。

| 合成输入 | 表达 | 判断边界 |
| --- | --- | --- |
| 100 → 120 次 | 增加 20 次（+20%），说明较上周 | 相对变化为差值 / 正基准 |
| 错误率 2% → 3% | 上升 1 个百分点；相对增加 50% | 百分点与百分比不能混写 |
| 0 → 12 条 | 从 0 增至 12；相对变化不适用 | 不写 +∞%、+100% |
| 0 → 0 条 | 数量无变化；相对百分比不适用 | 不把 0 / 0 伪装成 0% |
| 延迟 100 → 120 ms / 吞吐 100 → 120 次/秒 | 都增加 20%；分别说明延迟增加、同质量约束下吞吐提升 | 增减符号不自动映射 success/error |
| 当前已知、基准未知或口径不同 | 保留已知当前值，常显不能比较原因 | 不补零，不写持平 |

宿主拥有原始数值、币种、周期边界、时区、可比性、方向评价、公式及精度。负基准、累计计数器重置、不同对象或部分周期先定义业务含义，不能强套正基准公式。不平均每日百分比；需要汇总时按原始分子/分母及去重规则计算，不解析 `1.2M`、`1,200` 等展示字符串反推原数。这里的 tone 只是合成场景判断，不设全局“上涨即成功”规则。

## 成对异步读取

沿用[快照范围归属](ASYNC_SNAPSHOT_RECIPES.md)：比较查询身份包含对象、筛选、两侧周期、时区、单位/口径及本次请求代次。两侧观察作为一份完整快照提交，不能将新当前值与旧基准混算。返回快慢不同也不提前计算；忽略 abort 的旧响应仍需代次守卫。

可保留上次完整结果，但同时保留它的对象、两侧范围、观测时间和陈旧说明；当前选择单独表达。切对象/范围、失败、取消后旧快照不能冒充新范围。首次无快照显示等待或失败；有已知单侧值时可单独展示其查询身份与不可比原因，不能把另一侧补零。重试读取同一比较请求的两侧，不只拼接失败的一侧。

合成展台复用上述模式：两个不同延迟的 Promise 通过 allSettled 汇合，失败保留完整旧对；显式重新读取、取消、快速北区→南区和退出清理。宿主测试另外覆盖忽略取消的传输迟到结果。该局部示例不新增缓存、后台轮询或公共请求设施，也不代替生产数据/鉴权/统计验收。

验收包括上表算例、完整数值的键盘展开/收起、五主题、400/520/880局部容器与200%缩放、长范围名、失败重试、单侧提前完成、乱序/取消/卸载及正常/系统/手动减少动态。CSS zoom、原生网页缩放、DOM/AX与读屏语音分别记录。
