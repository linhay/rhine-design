# 日期筛选组合

本模式来自 [#10](https://github.com/linhay/rhine-design/issues/10)，适用于记录、报表等单视图的日期过滤。真实可交互样例为 `preview/DateRangeFilterGallery.tsx`，展台章节 `#date-range-filter`。它组合既有公共组件，不新增 `DateRangeFilter` 公共 API，不改变 npm 版本；支持这些能力的消费端可继续固定使用 0.6.0。

## 结构与信息

1. 简短的范围标签之后，使用一个 `SegmentedControl` 放置 2–3 个最常用、互斥的日期预设，例如今天、昨天、本周。一组只有一个外框；不使用三个完整 Button 拼接，不逐项重复粗边与硬阴影。超出这些预设的范围不选中任何快捷项。
2. 一个独立的 `Button variant="secondary"` 作为 `Popover` 触发器，持续展示已应用的完整起止日期及展开图标。不要仅显示「更多」或只在悬停时显示真实范围。跨年仍保留两端年份；同一天也保留明确的起止语义。
3. Popover 中放置低频预设与 `DateRangePicker`。低频预设即选即用；自定义字段是草稿，由「取消」和「应用日期」结束。用简短文字区分两种提交语义。
4. 使用 `Inline gap={2}`、`Stack` 和现有 `Divider` 组织布局。窄容器换行、浮层在视口内避让并可滚动，文字与控件自然增高；不缩小字号、不裁切日期、不在宿主复制组件 CSS。

按钮、分段单选、日期字段和浮层跟随所在主题。组件组合没有额外入场动画；减少动态由已发布组件与主题规则处理。

## 状态与提交

| 操作 | 已应用范围 | 草稿与浮层 |
| --- | --- | --- |
| 选择顶部快捷项 | 立即提交宿主传入的预设 | 关闭浮层 |
| 打开日期触发器 | 不变、不请求数据 | 从当前已应用值复制草稿 |
| 修改日期输入 | 不变、不请求数据 | 只更新草稿并显示字段错误 |
| 选择浮层内预设 | 立即提交完整范围 | 关闭浮层 |
| 应用完整且有效的日期 | 一次提交完整范围 | 关闭浮层 |
| 取消、Escape、关闭或点击外部 | 不变、不请求数据 | 放弃草稿；下次打开重新复制当前值 |
| 禁用 | 保留可读范围 | 所有快捷项和触发按钮禁用 |

应用必须同时满足两端非空、格式有效、起止顺序正确、宿主上下界约束与字段无错误。`required` 保留原生表单验证，`onValidationChange` 用于错误回显和按钮状态；它的回调异步发生，且空字段不自动返回错误，不能单独充当提交门禁。示例使用完整性和范围的同步条件，加上提交时 `form.checkValidity()`。

只有用户触发预设或有效应用时才通知宿主；初始回显、打开、输入、取消、关闭不触发查询。请求、加载、错误、分页复位及过期响应保护由宿主处理。请求失败时不得把草稿当作已成功取得结果；本模式不规定业务结果的缓存策略。

## 键盘与焦点

- `SegmentedControl` 使用原生单选。Tab 进入组，方向键切换；禁用项由浏览器跳过。无快捷项命中时仍可用 Tab 进入并选择。
- 日期触发器有完整可访问名称和 Popover 提供的展开状态；Enter/Space 打开，焦点进入浮层。不要把 Popover 伪装成 Menu：里面含表单，不能使用菜单项键盘模型。
- Escape、取消、应用和浮层内关闭按钮结束任务后归还触发器焦点。外部点击允许焦点留在用户刚点的控件，不强制抢回；它仍然不得提交草稿。
- 原生日期输入保留平台日期选择与键盘方式；错误由 `DateRangePicker` 关联。浮层过长时允许自身滚动，底部取消和应用必须可达。

## 宿主边界

`DateRange` 是 ISO 日期字符串 `{ start, end }`。日期预设、周起点、时区、首尾是否包含、自然日到 API 时间戳的转换和查询约束都属于宿主。不要在设计库固化「本周」的业务定义，也不要将单个产品的模型、角色、接口或内网地址带入组件。

展台固定基准为 2026-10-24，仅用合成日期。`DateRangeFilterExample` 只在 `preview/` 中作为真实组件组合与验证样例导出，不从包入口导出，不应当作新组件依赖。

## 验收

- 预设即选即用、自定义仅显式有效提交；空端、反向和越界不提交。
- 取消、Escape、关闭与外部点击不改变范围，重新打开草稿恢复；焦点遵循上述规则。
- 默认、自定义、跨年、长标签、禁用状态均可操作或正确禁用。
- Rhine、战术终端、橙趣三主题；400/520/880 宽度与 200% 缩放；无页面横向溢出、日期截断、浮层或操作不可达。
- 真实浏览器核对原生 radio 方向键、焦点归还、外点与浮层避让；JSDOM 不能替代布局和原生键盘证据。
