# 托盘用量与账号组合（#56，未发布）

本规范采用issue #56在2026-10-27的两条最新评论，取代旧“管理/查看用量/打开应用为次级动作、切换留在主窗口”的建议；最新偏好同时移除可见标题/关闭整行。本轮不改版本，不代表npm 0.11.1冻结制品或消费应用已经包含新能力。

## 信息顺序与动作

顶部从当前Agent的明确账号Select开始，显示完整账号名、本周期剩余额度及周期/时区。高频账号切换在上下文内完成；纯数值和名称不伪装成按钮。底部保留今日预估消费及币种、请求数、待计价数和更新时间。不放管理、查看用量或打开应用按钮。共享成员各列周期剩余，不累加百分比；多个连接共用同一上游时明确其共享关系。

未知额度显示未知/不可用，不传Progress的0值冒充。加载提供Skeleton，低额度有文字说明；未匹配连接不猜测余额。刷新失败可保留可信缓存但明确上次数据和时间；账号目录过期禁用切换。未登录仅显示登录提示，移除旧账号、用量和共享成员内容。

## 通用Popover API

`Popover.showHeader?: boolean` 默认true，保留已有可见标题及关闭按钮。设false只移除该行；必填、非空的`title`仍作为dialog的aria-label。不要用空title消除重复标题。触发器必须是具名、可聚焦并接收ref的元素，如IconButton；图标切换、外点和Escape沿用Radix，键盘关闭归还触发器，外点不抢走用户点击的焦点。隐藏头部适用于内容已有明确起点的简洁详情，复杂任务继续使用有可见退出入口的Dialog。

```tsx
<Popover title="账号与用量概览" showHeader={false} open={open} onOpenChange={setOpen}
  trigger={<IconButton icon="chart" label="切换用量面板" />}>
  <Stack>{/* Select / Metric / Progress / Notice / Skeleton */}</Stack>
</Popover>
```

只使用公共Popover的边界、滚动、缩放与主题能力，不覆盖其内部选择器、不另造产品托盘组件。浏览器浮层不是原生系统菜单或真实桌面托盘。

## 宿主切换契约

宿主保有已确认账号和待确认目标两个状态。立即锁住请求入口并禁用当前账号选择；请求完成前保留已确认账号和额度。只有确认成功才同时替换账号与额度；失败保留原值、允许同一目标重试。其他Agent和今日统计不跟随目标账号切换重置。加载、目录过期、连接处理中、未匹配和未登录不可切换；同步请求锁防止同一事件批次重复提交。

为反馈保留稳定空间。示例让空闲、处理、失败加重试、成功四种反馈共同参与同一网格的固有尺寸，非当前状态visibility:hidden且aria-hidden，不能聚焦；无需截断长错误或写死单行高度。状态切换保持同一视口下反馈区和内容高度；视口、文字长度变化可自然重排。

场景重置、身份失效、切换目录和卸载时取消模拟任务，并用递增请求标识拒绝迟到结果。实际请求取消、鉴权、目录校验、账号与额度的一致性由产品宿主实现；库不请求网络、不承诺业务事务。示例首次失败后可重试成功，仅为可复现测试。

## 展台

`#tray-usage` 和 `?fixture=tray-usage` 默认显示图标与展开面板；重置恢复初始合成数据。提供九种数据场景、长账号、首次切换失败，第二Agent和底部统计用于核对隔离。共享12成员使用Popover内部滚动。验收脚本 `scripts/check-tray-usage.js` 使用当前生产origin；`native=1`只选择原生缩放矩阵，运行前仍须在独立Chrome设置真实200%网页缩放。
