# 场景、组件与交互选型

本规范面向通用工具、管理界面和数据应用。先遵守产品明确的呈现偏好，再确定用户任务、信息是否需要持续可见、是否允许中断并选择组件。视觉沿用莱茵设计；行为参考成熟模式。`preview/PatternGallery.tsx` 提供可操作的选型示例。

密集账号摘要、可下载凭证的操作组及内容消融见[紧凑摘要与凭证操作](COMPACT_ACCOUNT_PATTERNS.md)：先依据用户任务保留身份、动作、结果和后果，合并重复提示，将历史渐进展示；使用真实 ButtonLink 与 compact 图例，不在业务层另造按钮外观。

**版本边界：**本页新增的 SideNav、Breadcrumbs、Steps、Drawer、Fieldset、ErrorSummary、StatusTimeline、TimelineLegend 及 Dialog.sidePanel 自 0.4.0 提供。npm 0.3.0 不包含它们；接入前核对安装版本及 `components/index.ts`。

## 选择与关联证据并排

在提交前需要比较资源、额度或健康记录时，使用 `Dialog sidePanel={预览}`：children放左侧选择与提交，sidePanel放右侧只读证据；description保留任务影响说明。最大宽960px，左/右约40/60，24px内边距与分栏间距；720px及以下上下排列，模态整体可滚动。避免将选择、长列表、图例与提交挤在同一窄列。右侧有导航区时，使用`sidePanel={closeButton => ...}`将唯一关闭按钮与右侧标题、说明入口放在同一行；导航与左侧标题顶端对齐，下面直接展示内容，不再预留关闭按钮空行。渲染函数必须展示传入的closeButton，保留Escape与焦点归还；纯内容sidePanel保持原布局。左右仍是一个模态、同一个焦点范围；默认选择不提交，即时保存模式须按下方规范明确说明。主任务先于预览的DOM顺序保留键盘阅读关系，使用默认160ms浮层动画，减少动态立即呈现。

## 弹窗高度与滚动归属

短任务和有界分页预览默认随内容增高，不为了固定外观给内部列表设置独立高度上限。少量溢出先让弹窗长高；现有Dialog仅在超过`100dvh - 32px`时整体滚动。保留服务端分页，不以取消内层滚动为由一次加载全部记录。

- 默认只有弹窗这一层滚动。短列表不声明“可滚动”，不为不可滚动容器增加Tab停靠点。
- 只有需要持续比较两个独立长内容区域、固定编辑器工作区等明确场景，才采用分区滚动；需有可识别的滚动边界、可达的关闭/操作入口，并单独验证键盘和窄屏。
- 最后一项的提示、焦点环与分页也计入所需空间。不能只让静态内容刚好装下，却裁切悬停或键盘详情。
- 高度由CSS与内容决定，不为内容变化添加整页高度动画。具体产品的每页条数、列表高度不固化为通用token。

## 信息密度与渐进展示

先确定用户在这里做什么决定，再决定常显内容；消融的是重复解释，不是决策依据或异常状态。

| 信息 | 默认位置 | 保留边界 |
| --- | --- | --- |
| 对象身份、核心指标、决定是否可操作的状态 | 每条记录常显 | 单位与统计周期明确；未知不能变成0 |
| 标题/数量、共享说明入口、关闭 | 区域顶部同一导航行 | 单一关闭入口；加载、空、错误状态仍可退出 |
| 重复的时间范围、粒度、排序机制、图例 | 共用说明Popover | 不藏起改变用户决策的影响或风险 |
| 某时段的时间与状态 | 悬停、键盘聚焦时显示 | 同时提供可访问名称；触屏也能聚焦/操作 |
| 失败、未知、数据不完整、关键陈旧状态 | 相关区域常显 | 不用减少文字来掩盖数据质量问题 |

## 补充说明与局部布局

### 与操作相邻的帮助

计算口径、匹配/排序方式、筛选解释等非阻断机制说明，入口放在对应标签或操作旁，用有明确可访问名称的问号按钮表达。44px 命中区与可见问号尺寸分开，不扩大到覆盖旁边的输入或按钮；不把说明拆成重复的独立常驻行。按钮名称说明对象，例如“查看费用计算说明”，而非只读出“问号”。

复用现有 Tooltip / Popover：简短文字由悬停与键盘聚焦可见，触屏点按必须能查看同一说明；长内容或有链接/操作的说明用可关闭 Popover。组件组合须实际验证 hover、focus、click/tap、Escape 与焦点归还，不把原生 title 或只响应 hover 的 Tooltip 当作触屏方案，也不为 hover 打开而抢走正在输入的焦点。不可逆影响、权限不足、当前失败、结果过期/不完整仍常显；帮助用于解释机制，不隐藏必要风险。

### 局部宽度与输入可用性

400px 视口并不代表控件有400px可用：需扣除宿主侧栏、卡片、Drawer 与字段分组的逐层内距。在 200% CSS zoom 下分别测控件边框、实际文本编辑区与邻接按钮，检查完整值、placeholder、标签、错误和焦点；原生日期必须实际聚焦并编辑最后一段，核对年月日与日历入口均未被挤掉。

整页 `scrollWidth <= clientWidth` 只是外层检查，不能证明内部没有裁切。验收同时保留局部截图与关键输入交互；控件的 scrollWidth 也不能直接反映浏览器原生 date 的内部编辑区。优先容器查询与单列重排、去掉重复内距，保留正常字号及操作目标，不通过全局 overflow:hidden、字体缩小或隐藏日历入口掩盖问题。

## 历史健康记录

`StatusTimeline({label,segments,startLabel,endLabel})` 接收按时间排序的 `{id,label,status}`；status仅限 healthy/recovered/degraded/failed/unknown。宿主负责证据分类、时区、缺失时段补unknown和陈旧说明；组件不计算评分、不查询后端。`TimelineLegend()`提供五种状态的文字和色块，恢复态另加纹理。两者从公共barrel导入并使用同一主题。

时间轴44px操作区，鼠标定位时段，键盘方向键及Home/End浏览；当前时间与状态同时提供文字和aria-valuetext，不能只用红绿表达。默认模式显示时间范围及详情；`compact`用于重复列表行，仅在悬停/聚焦时显示详情，日期范围仍供辅助技术读取。明亮健康色采用独立health tokens，恢复态斜纹，不扩散到正文颜色。空数组禁用滑块；宿主必须常显无数据原因。没有数据、采集不全或只有未确认输出时不得标为健康；历史有输出也不代表当前可用保证。时段颜色与数值原位更新，不做进度扫光、闪烁或数字滚动。展台“场景与交互 → 监控数据与告警”提供默认及紧凑双栏示例。

## 选择即保存的适用边界

适用于独立单项设置，且用户在选择前能够理解改变的对象与影响；不默认推广到多字段编辑、批量修改或不可逆操作。需要比较未提交方案时仍采用显式提交。

仅当宿主明确采用“选择即保存”，在选择前说明语义；初始回显/打开不提交，用户选择后锁定控件并显示保存中，服务端确认后显示已保存；有版本校验的接口使用返回的新revision继续操作。失败/未知结果不可显示成功或自动重试。此模式去掉重复提交按钮；说明信息按需查看，但影响范围不能消融。保存成功后可保持上下文继续查看关联证据；关闭只退出视图，不暗示撤销已保存内容。

## 侧栏导航

SideNav采用44px最小操作行、14/22文字、4px行间距，组间16px；图标可选，使用20px线性Icon且不替代文字。当前页用苔绿底、左侧2px细边界和aria-current表达，不使用容易误解为外链的箭头。少量并列页面优先一个分组；长名称自然换行、不截断、保持图标宽度。悬停仅120ms背景过渡，键盘焦点即时，减少动态沿用全局规则。

## 快速决策

列表顶部的搜索、排序与条件使用 [ListFilterBar](LIST_FILTER_BAR.md) 约束，最多两个常显条件，其余在同一 Drawer 内即时修改；结果反馈在抽屉内也可见。无搜索场景不增加空搜索，批量操作不混入筛选。该组件在 0.9.0 新增，`Toolbar` 的任意 children 组合不能代替这些约束。

日期过滤优先采用[日期筛选组合](DATE_RANGE_FILTER.md)：少量常用预设使用一个 SegmentedControl，具体范围由独立日期按钮持续显示，Popover 内组合低频预设与 DateRangePicker 草稿。预设即时生效，自定义显式应用；取消与关闭不提交。真实展台为 `#date-range-filter`，组合使用现有 0.6.0 公开组件，没有新增公共 API。

原生日期框的未完成片段可能同时满足 `value === ''` 与 `validity.badInput`，不能当作用户清空范围。DateField 保留未完成草稿并报告校验，DateRangePicker 汇总字段错误；补全原生片段后才回传日期值，范围限制继续由校验与宿主提交边界处理，明确清空与快捷项可丢弃草稿。整体重置必须通知局部日期状态，即使已接受日期字符串没有变化。验收使用真实键盘编辑日期片段，并证明期间没有扩大查询范围；只设置完整 ISO 值的测试不覆盖此行为。此修复随本地列表筛选候选验证，不倒推为既有已发布版本能力。

| 场景 | 组件组合 | 交互与状态 | 不宜使用 |
| --- | --- | --- | --- |
| 跨工作区、跨模块 | SideNav；仅真实父子层级按需加 Breadcrumbs | 当前页有文字、边界与 aria-current；平级工作区顶部保留状态与操作，不重复页名；路由变化后由宿主聚焦主内容 | Tabs 不代替全局导航；面包屑不显示浏览历史、不作必填标题 |
| 同一对象的内容页签 | Tabs；表单/设置区可用 `layout="content" fullWidth`（未发布），见[栏宽与分配](SUMMARY_TABS.md#满栏靠左76未发布) | 方向键选项、隐藏面板退出可访问树；焦点留在选项 | 不用一串按钮伪装页签 |
| 单视图指标或显示模式 | SegmentedControl | 原生单选，状态即时更新 | 不用于独立页面或执行命令 |
| 多字段配置 | Fieldset + TextField/Select + ErrorSummary | 提交后校验，摘要聚焦，链接回字段，保留已填值 | 不只弹 Toast；不在每次输入时抢焦点 |
| 线性配置流程 | Steps + Fieldset | 业务验证后推进，已完成步骤可返回；保留跨步数据 | 不自动走步骤，不拿步骤数估计后台进度 |
| 文件、笔记、来源等对象阅读 | 居中 Dialog + Tabs + KeyValue，见[工作空间对象阅读](OBJECT_READING.md) | 优先遵守产品居中阅读偏好；正文/来源/关联同窗切换，关联跳转关闭并交接焦点，返回恢复上下文 | 不以“Drawer 也是 modal”替代居中偏好；不堆叠阅读弹窗 |
| 明确采用侧边详情的列表场景 | Drawer + KeyValue | 模态侧栏限制背景操作与焦点；Escape 关闭并归还 | 需要持续并排比对且操作背景时选非模态分栏；长编辑、可分享详情选独立页 |
| 短时独立任务 | 自然高度 Dialog | 一个明确任务，按内容增长至视口上限；说明仅在帮助决策时展示，保留关闭路径 | 不叠加多层任务弹窗 |
| 多栏目设置 / 编辑工作区 | Dialog height + footer + navigation，见[设置契约](SETTINGS_DIALOG.md) | 宿主指定期望高度，空态/增删行/加载/错误/栏目切换外框稳定；头尾固定、正文与长导航独立滚动；footer直接按钮或Fragment | 不统一硬编码高度，不用整窗滚动或wheel转发替代正文滚动；草稿归宿主 |
| 不可逆操作 | ConfirmDialog | 具体对象、影响、取消与明确动作；等真实结果，失败保留上下文 | 常规保存无需二次确认；可撤销优先撤销 |
| 简短成功反馈 | Toast | 不抢焦点；自动消失前允许 hover/focus 暂停 | 不能作为关键错误唯一载体 |
| 持续错误、离线或权限状态 | Notice | 就地说明原因、影响、下一步；需行动的信息持续显示 | 不用自动消失通知掩盖失败 |
| 首次加载 | Skeleton / Progress | 已知结构用骨架，未知进度不写百分比 | 不伪造进度，不循环品牌标志 |
| 保存、刷新 | Button busy + 保留旧数据 | 防重复提交；刷新明确旧值和更新时间；真实响应决定成败 | 不清空阅读上下文，不提前显示成功 |
| 大列表查询 | ListFilterBar + DataTable + Pagination；候选 API 先核对安装版本 | 最多两个常显条件；宿主处理防抖、IME、取消与过期响应；服务端返回筛选排序分页 | 不为 UI 便利拉取全量本地筛选，不把低频条件继续堆在顶部 |
| 少量/较多互斥选项 | RadioGroup / Select | Radio 展开选项便于比较，Select 压缩较长清单 | Menu 是命令，不能代替选择器 |
| 多选 / 即时二态设置 | Checkbox / Switch | Checkbox 选择项；Switch 默认即时偏好；已有footer保存/确认的工作区允许仅更新草稿，显式确认才生效 | 不混同“选中”与“已生效” |
| 补充说明 / 局部交互 | Tooltip / Popover | Tooltip 不放操作；Popover 可交互；鼠标、键盘均可触发 | 必要说明必须常驻，不能只在 hover 下出现 |
| 次级命令 | Menu | 动词命名、危险动作区分；键盘导航，Escape 返回入口 | 不把长表单放入菜单 |
| 尚无数据 / 筛选无结果 | EmptyState | 分别给创建或清除筛选；读失败用 Notice | 不能把错误、无权限当作空列表 |
| 监控与告警 | Metric + Badge + DataTable + Notice | 数值、单位、时间范围、最后更新时间齐全；陈旧数据标记；告警有文字和处理路径 | 未知不能填 0；红绿不能是唯一编码；告警不闪烁 |
| 启动与品牌识别 | Logo / 启动编排 | 三角、细线、分块归位；仅启动或主动重播；就绪立即进入 | 日常数据变化不反复播放品牌动画 |

## 新组件契约

| 导出 | 输入与责任 | 键盘、焦点、边界 |
| --- | --- | --- |
| SideNav | `groups[{label,items[{id,label,href,icon?}]}]`、`currentId`、`onNavigate(item,event)`；icon为IconName，支持 nav 原生属性 | 原生链接可 Tab、打开新页；宿主接管路由时自行决定是否 preventDefault，保留修饰键语义；不自动滚动、鉴权或请求 |
| Breadcrumbs | `items[{label,href?}]`、`label`；最后一项是当前位置 | 带名称的 nav/ol；最后项 aria-current=page；只传真实父子层级，无 href 项为文本 |
| Steps | `items[{id,label,description?}]`、`current`、`error?`、`onStepChange?` | current 为从 0 开始的位置，等于项数代表完成；只允许点击已完成步骤；当前项 aria-current=step；错误有文字，不自动推进 |
| Drawer | 与 Dialog 相同：`trigger,title,description,children,open?,onOpenChange?` | 右侧模态面板；Radix 管理焦点限制、Escape 和归还；最近主题根继承动效偏好；可编辑内容需宿主保留草稿并在受控 onOpenChange 中处理未保存规则 |
| Fieldset | `legend,hint?,children` + 原生 fieldset 属性 | 原生 legend 分组、提示关联；disabled 禁用组内表单控件；不替代单字段标签 |
| ErrorSummary | `errors[{fieldId,message}]`、`title?`、`focusKey?` | 非空且 focusKey 变化时聚焦摘要；每次失败提交递增；链接聚焦已有字段并滚动到可见位置，不修改 hash 路由；fieldId 必须指向唯一、可聚焦字段；无错误不渲染 |

```tsx
// 提交时验证；不要在每次键入时递增 attempt。
const [errors, setErrors] = useState<FieldError[]>([]);
const [attempt, setAttempt] = useState(0);
function submit(event: FormEvent) {
  event.preventDefault();
  const next = name.trim() ? [] : [{ fieldId: 'name', message: '请输入名称' }];
  setErrors(next);
  setAttempt(value => value + 1);
  if (!next.length) { /* 宿主执行真实提交并处理 pending / success / failure */ }
}
// 在 form 内：
<ErrorSummary errors={errors} focusKey={attempt} />
<Fieldset legend="基本信息">
  <TextField id="name" label="名称" required value={name}
    onChange={event => setName(event.target.value)} error={errors[0]?.message} />
</Fieldset>
```

示例是组合片段；React hooks/types、组件导入、state 及 form 由宿主提供。异步校验必须忽略过期结果；摘要不负责业务验证。

## 动效按意图选择

| 意图 | 参数与效果 | 触发/结束 | 减少动态 |
| --- | --- | --- | --- |
| 指明可操作、选中 | 120ms 颜色/边界，按下 80ms | hover/press/选择；语义立即更新 | 即时颜色变化 |
| 呈现新内容、步骤 | 180ms opacity + 最多 3px | 新面板或当前步骤出现；单次 | 直接显示最终态 |
| 临时浮层、抽屉 | 160ms opacity，抽屉从右侧 3px | 打开；关闭立即解除遮挡并归还焦点 | 保留同样焦点规则，无位移 |
| 表单错误 | 即时文字、边界、摘要焦点 | 失败提交；纠正后重新验证 | 行为一致，无抖动 |
| 刷新数值、告警 | 原位替换，文字说明时间/严重性 | 真实数据更新 | 行为一致，无数字翻转 |
| 加载占位 | 已有 Skeleton/Progress 配方 | 请求结束或卸载终止 | 静态占位仍显示加载文字 |

共享 CSS token 是参数来源。仅声明必要属性，不使用 transition:all；优先 transform/opacity，不做整页高度动画、循环滤镜或滚动监听驱动的装饰。DOM 测量先读后写；能使用 CSS 的交互不另引动画运行时。

`/#motion` 有 12 组播放/重播/复位、4 倍慢放、逐例/全局减少动态示例。新增 Drawer 的弹层内重播只重启动画，不重新挂载、不清空输入或移动焦点；Steps 只模拟一次本步完成。错误反馈不加入“错误动画”，直接在 `/#form-workflow` 验证聚焦与纠错。

## 验收清单

1. 明确默认、加载、空、错误、成功、禁用、长文本各状态；不能仅凭颜色理解。
2. 键盘顺序符合阅读顺序；可见焦点；浮层 Escape 与焦点归还；错误定位不改变页面路由。
3. 400/520/880 宽度与 200% 等效重排无关键内容丢失；窄屏模态可滚动且关闭入口可达。
4. 系统/手动减少动态都保留信息；重复播放不会重执行业务动作或留下计时器。
5. 当前浏览器验证不代表原生 WebView、VoiceOver/Narrator 或完整 WCAG 审计通过。
6. 分别检查内容刚好装下、仅溢出少量、明显超出窗口三种高度；确认滚动归属，末条详情不裁切、不遮挡分页。间距同时测可见边界和命中区，不只读gap配置。

## 模板驱动批量设置（#78，未发布）

仅此明确模式把规则维护集中在模板编辑栏目；应用栏目只选择已保存模板与只读预览，不提供第二套规则编辑。保存模板与应用到目标分开，模板不携带目标集合或其他设置。默认保持原值，确认前逐目标展示实际差异、跳过与不变；混合开关使用单个Switch与短hint，宿主持有未修改状态，切换才统一草稿，footer显式确认才生效。保存更新已选模板时使选择失效或固定可见版本，不能新名称配旧规则。使用受控 `MappingEditor` 统一来源→目标、稳定id、隐藏视觉标签、错误和增删焦点，业务校验/权限/持久化归宿主。完整契约及合成组合见[模板驱动设置](TEMPLATE_SETTINGS.md)。

二态批量设置优先单个Switch；未操作保持各对象原值，混合短hint与未修改状态由宿主管理，不增加三态选择器。单对象固定身份、批量独立对象栏与确认快照见[模板设置组合](TEMPLATE_SETTINGS.md#对象上下文与最小组合)。
