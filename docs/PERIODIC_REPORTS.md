# 周期报告与跨日来源（Web 组合配方，未发布）

承接 [#152](https://github.com/linhay/rhine-design/issues/152) 与[产品侧验证背景](https://github.com/linhay/rhine-design/issues/152#issuecomment-6559766428)。适用于需要周期活动摘要与来源核对的产品；不是所有报告的强制样式。组合已有 Select、Notice、Badge、Button、Stack、Disclosure、Link 与语义标题，不新增业务组件、模型服务或计划引擎。

源码展台 `#periodic-report`；独立验收入口 `?fixture=periodic-report`。源码配方尚未 npm 发布，产品设计稿证据不作为本库验收。

## 宿主输入和时间边界

宿主提供对象身份、周期稳定键、明确起止、时区、周起点、计划规则、下次计划及每日材料。日期显示采用宿主提供的日历日期；查询使用明确带偏移的时间区间，不通过运行设备的本地时区猜自然周/月，不把 7×24 小时当作所有时区的自然周。真实时区规则、夏令时、计划执行和权限由宿主校验。

合成示例固定 Asia/Shanghai、周一开始：周范围 `[2026-10-19T00:00:00+08:00, 2026-10-26T00:00:00+08:00)`，月范围 `[2026-10-01T00:00:00+08:00, 2026-11-01T00:00:00+08:00)`。含起点、不含终点；可读日期分别到 25 日及 31 日。计划文字为历史固定样本，没有运行 scheduler、后台轮询或真实自动生成。产品若允许任意日期，复用 DateField/DateRangePicker 的草稿与校验契约；本例只选择两个明确周期，不增加伪可编辑日期。

### 局部产品约束：月报仅展示已结束自然月

依据 [2026-11-02 产品纠正](https://github.com/linhay/rhine-design/issues/152#issuecomment-6573136134)，以下仅适用于该桌面报告产品，不作为所有周期报告的默认规则，也不改变上面的固定合成展台。

- 宿主以统一业务时区中的当前日历月份为边界；没有有效历史选择时，默认上一自然月，允许的最新报告月也是上一自然月。月内任意一天都按此规则判断，不以当天是否到达计划执行时间代替月份是否结束。合成业务日期 `2026-11-02`、时区 `Asia/Shanghai` 时，默认 `2026-10`，报告日期为 `2026-10-01` 至 `2026-10-31`；`2026-11` 及未来月份不能显示为已有月报，也不能列为历史缺口。
- 宿主统一默认值、日期上限、手工输入的接受判定、日报切换月报、旧 URL 规范化与服务端校验。以日历日期选择所属月份时，日期上限为上一自然月的最后一天；月内任意有效日期归入同一个报告月。复用 [DateField 的受控值、max/hint 与草稿校验契约](APPLICATION_COMPONENTS.md#表单)，`max` 只承担交互和字段有效性约束，不代替宿主接受校验，也不自动改写越界值。空值、未完成草稿、非法日期不能被当作已接受月份发起查询或生成。
- 从日报切到月报或打开旧 URL 时，先按业务时区解析、校验并规范化月份，再加载该月份。合法且已结束的历史月份保持原选择；当月、未来月或无效参数由宿主明确规定回退至默认月或拒绝并提示，界面选择、URL 与请求必须一致，不得保留越界标签却请求默认月。直接请求服务端同样须检查月份边界，不能只依赖前端控件；原产品的权限及可查历史下限仍由宿主定义。
- 自动任务的执行时间与报告所属月份分别记录。例如在 `2026-11-01 09:00 +08:00` 执行的上一自然月任务，其报告月为 `2026-10`。补跑或延迟执行也不能直接用执行月覆盖报告月；已结束只代表具备报告时间范围，不代表生成成功或证据完整。合法历史月份的缺失日报提示、确认空日报与生成状态继续保留。

#### 宿主接入验收清单（非运行时通过记录）

以下期望使用合成时钟与公历，业务时区固定为 `Asia/Shanghai`；所有日期均指该时区的日历日期。文档例子可独立核算，但清单需在消费方接入时验证；本次未新增日期算法、公共 API、服务或展台，既有脚本也不覆盖这些新增宿主规则。

| 场景 | 应核对的结果 |
| --- | --- |
| 月内任意日 | `2026-11-01`、`11-02`、`11-30` 均默认 `2026-10`，上限 `2026-10-31`；历史月份内任意有效日期归入同一月，手工越界输入不成为接受值 |
| 跨年 | `2027-01-01` 默认 `2026-12`，日期上限 `2026-12-31`，年份不沿用执行年 |
| 闰年 | `2024-03-01` 默认 `2024-02`，日期上限为 `2024-02-29`；非闰年 `2026-03-01` 对应 `2026-02-28`，不能固定减去 30 天 |
| 业务时区月界 | 运行设备的时区不改变业务月界：`2026-10-31T15:59:59Z` 在业务时区仍为 10 月，默认 9 月；到 `2026-10-31T16:00:00Z` 已是 11 月，默认 10 月。默认月与上限按同一边界更新，合法历史选择保持，请求与已接受月份一致 |
| 日报切月报 | 业务日期为 `2026-11-02` 时，当前日报 `11-02` 不直接成为 11 月月报；按宿主已定义的回退或拒绝规则处理。已结束月份中的日报切换后保留对应历史月 |
| 当月/未来及旧 URL | 在同一合成日期直接打开指向 `2026-11`、`2026-12` 的链接，或输入非法/未完成日期，验证规范化或拒绝、提示、URL/选择/请求一致；绕过前端的服务端请求也不能接受越界报告月，不产生伪历史缺口 |
| 历史保留与任务归属 | 合法 `2026-09` 历史链接和选择不被默认 10 月覆盖；缺失日报提示仍在，确认空日报仍独立。11 月执行的 10 月任务保持 10 月报告身份，执行时间不冒充报告日期 |

## 局部产品配方：目录先可操作，详情按需读取

依据[大型月报消费经验](https://github.com/linhay/rhine-design/issues/152#issuecomment-6576088767)，当完整来源体积明显大于目录时，宿主可以先返回当前权限下的对象身份、覆盖、生成状态与短摘要，选中对象后再读取完整来源。完整证据不作为目录首屏的前置条件；此方案不规定所有产品的数据分页方式、缓存或请求预算。搜索与权限继续由宿主后端处理。

目录与详情分别维护读取状态。详情加载中明确等待，不能用“无事项”代替；只有当前范围的有效空响应才显示空结果。详情失败保留可操作目录及其已确认摘要，提供只读重试，不触发生成。同范围旧详情可按[异步快照配方](ASYNC_SNAPSHOT_RECIPES.md)保留并标明归属；没有快照则显示独立错误，不伪造空材料。复用已有文字状态、Alert、Button、列表和详情组合，不新增组件或全局调度。

详情的请求和接受结果必须同时绑定对象、周期、筛选与权限上下文。切换对象或报告窗口、改变筛选、权限失效及卸载时取消旧等待，并拒绝忽略取消的迟到结果；旧成功和错误都不能覆盖新选择。只读重试仅读取当前详情，不暗中重新生成、重载整个目录或扩大可访问范围；读取完成不抢焦点，重试入口卸载时沿用宿主稳定入口的条件交焦规则。

宿主接入时独立核对：延迟详情期间目录仍可操作；快速切换后旧响应被拒绝；详情失败只重试详情且目录保留；加载、有效空和失败不混淆；筛选或权限变化后详情归属一致。这是组合契约检查清单，不是本库现有展台已覆盖渐进传输的运行时通过记录。原评论中的规模、延迟及冷热资源结果属于该消费产品的合成验证自报，不外推生产性能、数据库冷缓存或模型质量；本次仅补文档，不修改消费实现或已冻结发布候选。

## 三类事实分别呈现

| 事实 | 表达与边界 |
| --- | --- |
| 生成状态 | 尚未生成、排队、生成中、失败、结果待核对、AI 生成完成；完成只说明摘要产物生成，不说明工作完成 |
| 日报覆盖 | 每个预期日期分别是有材料、已确认空日报或缺失；缺失数常显，具体日期按需展开。缺失不能用空数组伪装为已确认空日报 |
| 材料核对 | 使用 `sum(verified) / sum(total)`，明确分母只含已收到材料；不能平均每天百分比，也不能将缺失日期自动计为零条。无材料分母时显示不适用，不显示 100% |

示例两天材料为 2/2 与 1/8，总计 3/10=30%，其余日期明确区分空与缺失。这不是工作完成率，也不是缺失日期的估算覆盖。业务数据须保证计数非负、核对数不超总数，按稳定材料身份去重；本例固定合成计数不提供通用聚合服务。

## 摘要、合并事项和安全来源

阅读顺序是摘要 → 合并事项 → 来源日期 → 按需展开的每日活动与来源链接。合并相同事项不丢每日出处或把连续讨论改写为完成。失败/未知期间每日材料仍可阅读；若已有摘要，标明上次产物并保留。资料为长中文时自然换行，动作与最后一日仍可滚动到达。

模型只能建议引用，宿主负责来源存在、当前对象/周期/权限、协议与目标校验，以及 Markdown/HTML 消毒。不得直接将模型 URL 变成可点击链接。示例只接收合成来源 ID，由当前周期的白名单映射到只读本地来源页；`javascript:alert(1)` 与不存在的 ID 反例显示未验证引用而无链接。新标签页明确标记并使用 `noopener noreferrer`；非法来源入口显示不可用，不提供绕过路径。这是有界演示，不代表通用 URL 或内容安全实现。

## 操作、异步与焦点

- “生成当前对象报告”仅触发当前对象/周期的一次显式操作。本地生成请求保持 busy 与原动作焦点；同步守卫阻止连点。服务端任务状态与本地请求独立：已知排队/生成中禁止重复生成，但仍可刷新，不凭任务状态显示本地等待或停止入口。刷新是独立只读请求，不隐式生成、不重试生成。
- 状态读取失败保留原生成状态、摘要与每日材料，并显示独立错误。生成 Promise 拒绝只表示没有收到确认，必须进入结果待核对并阻止重复写入；只有宿主明确返回 failed 才允许直接重试。失败/未知不自动重试；结果未知时禁止再次生成，必须先只读核对；核对仍未知则继续阻止写入，不误报成功。这里没有真实服务的取消确认。合成 transport 按 scope 保存已确认结果，连续刷新不会恢复初始场景；“生成响应丢失”演示合成服务已完成但响应丢失，界面先保持未知，只有显式刷新后才接受完成。
- “停止等待”取消本地等待和计时器，不宣称后端工作已取消。若焦点位于即将消失的停止按钮，返回稳定可用的刷新按钮（生成在待核对期间禁用）；用户已移到别处则不抢焦点。错误保持触发动作焦点，反馈原位可读。
- 宿主将对象、周期与场景作为实例 key，切换立即卸载旧实例。AbortController 加请求代次保护同时拒绝忽略取消的迟到响应，旧成功/错误不能覆盖新选择或在新对象宣告成功。卸载清理计时器及监听；不把旧范围缓存贴到新范围。
- 正常、系统减少动态、手动减少动态完成同一路径；不让动画表示实际任务进度。复用现有组件动效，无新自动播放。

原生浏览器缩放、读屏语音、真实模型质量、生产服务/任务持久化、计划执行、跨时区服务端日期计算尚未验证；合成计时器与 JSDOM 不证明这些行为。没有 npm 发布、原消费升级或 UIKit 变更。
