# 安全只读富文本（0.15.0；#222）

RichText({label,source,highlight?,links?,initialBlocks?,copy?})是有限Markdown原文入口，保留MessageContent的children表面和MessageRenderer分派。可组合到报告/消息，不让宿主复制另一套排版CSS，也不接管原文、搜索请求、消息分页、模型调用或附件。组件拥有有界展示计数与展开焦点交接，复制复用CopyButton的失败/重试及卸载代次。

支持段落、#至###映射为h2/h3/h4、单层有序/无序列表、**强调**、*斜体*、~~删除线~~、单反引号行内代码、三反引号围栏和只读管道表格。不宣称CommonMark/GFM完整兼容；不做嵌套列表、HTML、图片、语法着色、公式、脚注或自动链接。无法识别/不完整语法保留为文本；未闭合围栏按原文pre呈现。代码保留换行/空格，源CRLF只为显示规范化，复制仍是原始source逐字节字符串。

HTML、脚本、事件、SVG字符串都通过React文本输出，不用innerHTML、eval或外部资源加载。图片Markdown按文本显示，无自动远程图片请求。链接默认links=source，仅展示来源文字与经校验URL，不导航；navigate显式启用http/https、禁止控制/空白字符和userinfo凭据，目标新窗口并加noopener noreferrer。javascript/data/协议相对/不支持地址不生成锚点；copy不从渲染DOM读取。

highlight是大小写敏感的字面搜索，不改source、代码或复制值。同一段落/标题/列表项/单元格中的匹配可跨strong/em/del/code等行内边界分段mark，中文与emoji按原字符串定位；不跨列表项/单元格/独立块，也不搜索只读来源旁的辅助URL文字。清除词恢复原文显示；不建立索引或发请求。

预算是公开边界：source上限131072个UTF-16码元，超限不解析，明确提示宿主分页但仍可复制完整source；单个行内块超过16384按literal，嵌套8层/32768扫描步后降为文本；列表最多200项、表格40列/200行，超限整块作为原文。highlight最多256码元，每个块最多1000非重叠匹配。initialBlocks默认40，每次显式追加同量，限制1–100；未显示块不挂DOM，新增source从本次初始批次开始。不自动读取全部消息、不因搜索而无限展开。

代码/表格有具名键盘滚动区域，最长360px，外层不裁掉正文；普通长行自然折行。展开前同步把焦点交给稳定内容容器，避免最后一页移除按钮后失焦。复制完整源文本，失败可重试，不把成功写成业务保存；来源变化时旧复制结果失效。

#rich-text真实展台有中英文/emoji/跨格式搜索、恶意HTML与链接、长代码/表格、空/55段展开/超长/坏格式、合成复制失败恢复与MessageContent组合。合成复制路径只核对传入值，不冒充系统剪贴板权限成功。布局、键盘和动态偏好按本轮实测分别报告，未覆盖语法和原生读屏不外推。registry0.14.0不含此导出，固定候选、正式发行和消费替换分别核对。
