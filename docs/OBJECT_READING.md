# 工作空间对象阅读

文件、笔记与文字来源采用居中 Dialog 专注阅读。先遵守产品明确的呈现偏好；“模态”描述焦点与背景交互限制，不描述位置，右侧 Drawer 也是模态，但不等于满足居中阅读偏好。已有 Drawer 场景继续保留；只有持续并排比对、需要操作背景或独立可分享页面时，才明确评估非模态分栏或独立页。不要用模态 Drawer 承诺背景可操作。

真实展台：`/#object-reading`。隔离验收入口：`/?fixture=object-reading&theme=rhine&zoom=2`；theme 可选 rhine / arknights / neo-brutalism / neutral / graphite。所有资料、目标与对话均为合成，不连接文件系统、模型、权限或消息服务。

## 组件与版本

组合现有 Dialog、Tabs、ListFilterBar、Breadcrumbs、Surface、Button、KeyValue、Notice 与 EmptyState。短列表使用语义化 ul/li；大量数据可用 DataTable 与服务端分页。不增加文件管理器、阅读器或基础 modal 公共导出，不复制私有 CSS，不覆盖 Dialog 宽度。正文用原有 480px 最大宽度，窄屏自然换行；标题、路径与长中文不截断、不缩字。

本次规范与展台属于 #61 源码新增，**源码完成不表示 npm 已发布**。使用时核对固定制品和导出，尤其 `Dialog.onCloseAutoFocus`；不要仅凭同为 0.11.1 的版本标签推断实现相同。本组合不使用 `height` / `footer`，普通 Dialog 整体滚动；#18 管理有界 Dialog 的稳定头尾，非本组合额外 API 的前置。若宿主明确需要固定头尾，读取该版本的 [设置 Dialog 契约](SETTINGS_DIALOG.md) 并重新验收其滚动归属。

局部正文字号、实际行长、内容保真与阅读位置边界另见[长文排版配方](READING_RECIPE.md)；它不新增Reader/Prose或持久阅读器。

## 状态所有权与阅读闭环

1. 宿主管理目录/路径、查询、类型、选中对象、每对象当前页签与阅读位置。Breadcrumbs 仅表达真实层级，目录 Select 切换目录；返回不是面包屑历史。筛选即时改变结果但不清除已读位置。
2. 明确命名的原生 Button 作为 Dialog trigger；Enter 打开，Tab/ShiftTab 限制在窗口中，Escape 或唯一关闭按钮退出并回到原入口。焦点可见，正文和关闭入口通过同一滚动范围可达。不要给短正文额外增加滚动容器。
3. 正文、来源、关联使用一个 Tabs，保留一个 Dialog；切换不返回底层列表，不叠加第二个阅读弹窗。正文末尾等外部按钮切换页签时，将焦点移到新页签，不能留在已隐藏的旧面板。元信息常显：归属和访问权限是两条事实，分享或拥有对象不意味着可读取所有内容。
4. 导航关联目标/对话前先记录上下文，关闭 Dialog。只在这次导航的 `onCloseAutoFocus` 中 `preventDefault()`，随后挂载目标页并聚焦其主标题。普通关闭仍使用默认归焦；不要用延迟计时器与默认焦点抢夺。
5. 从关联页返回时恢复原目录、查询、类型和选中对象，并聚焦原阅读入口。再次打开保留页签，切回正文恢复阅读位置；在真实路由卸载列表时，将状态存入宿主路由/页面存储，不能依赖组件仍挂载。对象已删除或权限变化时重新校验，并把焦点回退到列表标题或查询输入，明确说明无法恢复的原因。
6. 普通 Dialog 的滚动位置可通过内容节点的标准 `[role="dialog"]` 祖先记录，无需查询私有类名。展台为每个对象、页签保留有效 scrollTop，恢复时机和焦点归属见下节。未来改用分区滚动时，应由宿主重新选择实际滚动区域并验收，不能照搬普通 Dialog 的记录方式。
7. 阅读和关联导航不改正文、不触发保存、不将消息标为已读。重试只重试当前读取；“重试正文”和“完成模拟加载”有600ms合成等待及取消入口，用于验证恢复/主动操作/清理，成功不证明真实请求成功。真实异步请求须由宿主管理取消、迟到响应和权限校验。

## 恢复位置与焦点所有权

正文加载、失败或无权限占位不写入正文记忆。等待正文与实际滚动范围就绪后恢复，超出最终范围时夹到末尾；聚焦页签引起的浏览器自动滚动也不覆盖正在离开的正文位置，用户主动滚动仍可更新位置。

恢复后同步核对焦点可见性：已有可见焦点保留，否则聚焦当前位置完整可见的正文句子（tabIndex=-1、preventScroll），不把键盘焦点留在屏外页签。若窄屏长元信息使当前位置没有可见正文目标，才将选中页签 nearest 滚入视口。句子仅是展台内部焦点落点，不是语义位置缓存或公共 API。

用户主动滚轮/触摸滚动、指针或键盘操作会让旧恢复让位；明确的重试/完成模拟加载发起新恢复意图，因此用 Tab 找到重试入口后仍能恢复。离开页签、关闭（含退出动画）、对象切换/卸载取消 animation frame、观察器、监听器与待完成的模拟请求。

## 异常状态

| 状态 | 内容与退出 |
| --- | --- |
| 空目录 | EmptyState 说明尚无资料，提供返回资料目录 |
| 无搜索结果 | 保留目录/查询/类型，提供清除筛选 |
| 加载中 | Skeleton 明确“正在加载正文”，元信息、页签和关闭仍可达 |
| 正文受限 | Notice 明确仅元信息，不渲染正文，也不提供来源或关联绕过入口 |
| 格式不可预览 | 保留对象身份、权限和版本，说明无法预览，允许关闭返回 |
| 正文加载失败 | 就地 Notice 与重试，仍可关闭，不伪装为空目录 |
| 来源不可用 | 明确失效或不可访问，无原文链接；不可保留隐藏或备用绕过入口 |
| 暂无关联 | EmptyState，无假目标/假链接 |
| 关联不可用 | 明确当前无法跳转，不渲染可执行关联动作 |

## 验收边界

五主题 × 400/520/880 × 100/200% CSS zoom（恢复回归使用600px短屏）：长标题/路径/正文、单个居中 Dialog、唯一关闭、末段、键盘陷阱、关闭归焦、目标/对话往返、上下文/阅读位置保留和异常状态。系统减少动态与手动 reduced 分开验证，并保持同样的焦点规则。JSDOM 只证明状态契约；布局与滚动须检查生产构建及固定包的实际浏览器。CSS zoom 不代表原生网页缩放，也不代表屏幕阅读器或真实权限服务验收。

本轮精确源码、固定制品、通过结果和保留失败见[对象阅读验收](OBJECT_READING_VERIFICATION.md)。
