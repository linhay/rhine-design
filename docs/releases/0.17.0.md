# 0.17.0 发行说明

本页记录 Web 0.17.0 的接口范围和支持边界。渠道可用性以 [GitHub Release](https://github.com/linhay/rhine-design/releases/tag/v0.17.0)、[npm 精确版本](https://www.npmjs.com/package/@linhey/rhine-design/v/0.17.0) 与 [Pages 展台](https://linhay.github.io/rhine-design/) 的实际回读为准。安装前核对版本与制品校验和；源码和展台不能代替实际安装包。

## 本版改动

- [#235](https://github.com/linhay/rhine-design/issues/235)：窄菜单打开受控 Dialog 后，一次 Escape 关闭允许关闭的弹窗并归焦。交接中的旧入口提示不再抢先接收 Escape。
- [#228](https://github.com/linhay/rhine-design/issues/228)：选择框可显示调用方给出的半选。可选的正文点击只切换展开，不触发行命令或选择。级联、禁用和导出仍归调用方。
- [#225](https://github.com/linhay/rhine-design/issues/225)：`outsideDismiss` 默认保持现状。关闭后，背景和外点不关闭，Escape 与关闭按钮仍可用，直到 `closingDisabled` 统一阻断。
- [#219](https://github.com/linhay/rhine-design/issues/219)：新增 `robot`、`envelope`、`save`、`verify`。未知名字仍报错。不提供企业微信商标图形。
- [#222](https://github.com/linhay/rhine-design/issues/222)：只读预览可隐藏内部按钮。补充旧式下划线强调和缩进代码，以及默认关闭的不区分大小写字面高亮。

沿用 0.16.0 的依赖和旧版有效调用。数据、权限、请求和保存仍归宿主。

## 支持与验证

继续提供 React 19 的 TypeScript/TSX、CSS 和 SVG 源码。浏览器范围为 Chromium/WebKit 自动化和 CSS zoom。没有覆盖完整 Safari、原生网页缩放、系统输入法、系统剪贴板、读屏或真实消费项目。0.16.0 与 0.15.0 的 tag 和发行包不原位替换。
