# 0.18.0 发行说明

Web 0.18.0 收录 [PR #257](https://github.com/linhay/rhine-design/pull/257) 的 18 项控件和展台交互改进。渠道以 [GitHub Release](https://github.com/linhay/rhine-design/releases/tag/v0.18.0)、[npm 精确版本](https://www.npmjs.com/package/@linhey/rhine-design/v/0.18.0) 和 [Pages 展台](https://linhay.github.io/rhine-design/) 的实际可用性为准；Pages 不代替安装包验证。

## 主要改动

- **输入与对话（#237、#238、#242、#247）**：宿主能接管 Enter；异步失败后可以继续编辑；会话各自保留草稿与附件，引用入口之间不重复填入 @；引用选择与发送分开。
- **操作与键盘（#239–#241、#248、#249、#253）**：禁用图标阻止原生表单提交，动态页签保留键盘入口，按压不移动命中区，受控确认重开不带旧错误，RTL 滑杆对齐刻度和交互方向，异步翻页保持焦点。
- **候选和浮层（#243–#246、#250）**：重排或移除时保持候选身份正确，提及和补全遵守宿主字数上限，级联按完整分支表达选择，受控弹出层按当次交互报告关闭原因。
- **文件与数据（#251、#252、#254）**：外部表单重建不丢附件，移除动作可读出文件目标，可见行半选与表头全选一致。

## 升级检查

- `Composer.busy` 期间编辑器改为只读、保留焦点，并继续禁止重复提交。若宿主以前通过原生 `:disabled` 判断忙碌，请使用宿主持有的忙碌状态；显式 `disabled` 继续原生禁用。
- `Composer.onKeyDown` 先于内建发送运行；宿主可用 `preventDefault()` 接管 Enter。无自定义拦截时，Enter 发送、Shift+Enter 换行。
- 未改变 npm 依赖、组件导出或 iOS 版本。网络、权限、保存结果和草稿持久化仍归宿主。0.17.0 及旧版制品不原位替换。

## 支持与验证

提供 React 19 / Vite 消费的 TypeScript/TSX、CSS、SVG 和评审入口。覆盖浏览器 Chromium/WebKit 及 CSS zoom；不以该证据外推完整 Safari、原生缩放、系统输入法、读屏、实际业务或生产消费者。
