## 范围与兼容

- 相对0.13.0新增总览对应的布局、导航、录入、展示与反馈组件及可选参数，包含字段元数据/约束、宿主读取反馈、图片资源状态、真实目标Tour、Tree/虚拟列表与局部密度。Rhine按自身契约实现，不是Ant Design API兼容层。
- 质量修复包含关闭/移除焦点、稳定条目身份、禁用入口、动态手风琴、树缩进、图表说明、重复错误、主题业务文字和展台样式边界。既有组件默认调用保留，运行依赖未因质量收口增加。
- 内部组合与展台复用已有Text、Button、布局和浮层；保留原生HTML/表单语义与Radix基础设施。两处深导入的定向检查不是全库依赖图审计。
- CountBadge保留99+摘要并提供完整数值title/aria-label；它不是可操作明细入口，也不承诺实际读屏语音。
- 业务数据、权限、请求、文件上传与保存结果由宿主拥有；本次不升级真实消费项目、不修改UIKit。

## 支持范围与验证要求

发行包仍提供React19使用的TS/TSX、CSS与SVG源码，验证构建器为Vite，开发/发行检查使用Node24。主入口、独立theme/CSS/SVG、review和Node review/vite入口分别检查。SSR、其他构建器及直接Node执行组件TSX不在兼容声明内。

- 自动化浏览器目标：Chromium与WebKit；后者不冒充完整原生Safari或iOS验收。Firefox为N/A。
- 验证五主题、400/520/880窄有效宽度、CSS zoom1/2和相关真实键盘/焦点/资源路径。CSS zoom不是原生网页缩放，DOM/ARIA不是读屏语音。
- 正常、系统减少动态与宿主手动减少动态分别执行。未覆盖真实业务服务、系统文件框或实体扫码。
- 候选必须完成完整`npm run check`、新tarball仓外安装、逐文件与精确Git提交匹配、入口/类型/CSS/SVG和生产交互检查。旧候选的831项与旧包的浏览器结果不能自动绑定新发行。
