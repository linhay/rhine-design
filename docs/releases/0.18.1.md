# Web 0.18.1 发行说明

本版是兼容性补丁：恢复可见焦点和状态辨识，修复继续阅读与代码字体；不增加公开导出、主题变量、依赖或必填参数。

## 组件修复

- RichText：行内与围栏代码统一读取 `--rhine-mono`（[#259](https://github.com/linhay/rhine-design/issues/259)）。「继续显示」后把焦点交给首个新块并就近滚入视口，宿主已主动移动的焦点不会被抢回（[#260](https://github.com/linhay/rhine-design/issues/260)、[PR #261](https://github.com/linhay/rhine-design/pull/261)）。
- SelectionCard：悬停不覆盖已选底色（[PR #264](https://github.com/linhay/rhine-design/pull/264)）。
- Combobox 及多选候选：独立轮廓标示键盘或指针的当前目标；原选中状态、值、背景及多选勾选保留。
- 战术主题：危险菜单项高亮复用已有错误底色，保留危险图标及活动侧线；已选 SegmentedControl 的键盘焦点环画在未裁切的操作区，保留斜角、键盘语义和点击范围。

## 展台配方

- [长报告](https://linhay.github.io/rhine-design/#rich-text) 只在正文段落与列表使用 16px／28px，普通富文本、聊天和控件默认字阶不变。
- [设置和同步记录](https://linhay.github.io/rhine-design/#spacing) 默认用 B：留白分组、纯表格无外围内距，保留 A 供对照，不改变公共控件密度（[PR #263](https://github.com/linhay/rhine-design/pull/263)）。

## 安装与验证范围

```sh
npm install --save-exact @linhey/rhine-design@0.18.1
```

沿用 React 19、Vite 以及已有 CSS、SVG 和评审入口。验收区分生产展台、实际安装包与浏览器样本；不外推至真实消费应用、原生缩放、物理触控或读屏。制品和校验文件见 [GitHub Release](https://github.com/linhay/rhine-design/releases/tag/v0.18.1)，实际可用性以 [npm 精确版本](https://www.npmjs.com/package/@linhey/rhine-design/v/0.18.1) 为准。iOS 不在本次发行范围。
