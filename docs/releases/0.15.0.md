# 0.15.0 发行说明

本页记录0.15.0的接口范围、兼容决定与验证边界。正式渠道状态以[GitHub Release](https://github.com/linhay/rhine-design/releases/tag/v0.15.0)和[npm精确版本](https://www.npmjs.com/package/@linhey/rhine-design/v/0.15.0)的实际回读为准；源码分支或相同版本文本本身不证明已发行。最终校验和及实际发布结果记录在Release中，已发布制品不原位重打。

## 范围

- #219/#220：同源动作/对象/状态图标、只读iconNames与独立PlatformMark；固定Bootstrap Icons几何、完整MIT许可和NOTICE随包保留。不检测系统或执行下载。
- #221：受控树展开、只读节点内容与拖放/表单等价移动提案；共用Tree引擎，实际授权、修订和持久化归宿主。
- #222/#223：有界只读RichText与原文复制、跨格式字面高亮；TrendChart增加compact密度与完整单位控制，保留未知断点和原始数据。
- #224–#229：结构化只读Tooltip、Dialog关闭门禁/无触发归焦/明确结果、RangeSlider与动态范围、RemoteMultiSelect和TreeSelect生命周期/字段关联、DataTable语义行激活/匹配/表头帮助。
- 收录此前已合入主线的#216局部诊断组合规范和#217日期清空归焦修复；它们未包含在旧registry0.14.0中。

## 兼容与所有权

既有有效调用及默认模式保留；新增API按对应类型与[交互契约](../INTERACTION_CONTRACTS.md)使用。ConfirmDialog的explicit结果模式仅`true`或`{status:'success'}`接受成功，默认legacy保留旧void语义。选择组件的关闭请求不等于已接受关闭；过期原因回到programmatic，跨窗口异步接受由宿主在实际open=false时显式closeReason并在重开时清除。原生fieldset禁用传递到游标指针和Portal内容，first legend例外保留。

数据、草稿、权限、请求代次、后端写入、上传/下载结果和真实业务验收始终由宿主负责。本版本没有升级真实消费项目或修改UIKit。

## 支持与验证

发行包继续提供React19的TS/TSX、CSS与SVG源码；主入口、theme/CSS/SVG、review与Node review/vite分别验证，开发/发行检查使用Node24和固定lockfile。SSR、其他构建器或直接Node执行组件TSX不属于此次兼容声明。

发布门禁为精确候选的全量测试、类型/生产/两评审构建、公开导出目录/质量/包检查；固定tarball的离线仓外新安装、peer身份、全部文件字节、公开类型和实际入口另验。Chromium/WebKit生产和实际固定包流程分别记录，不能将旧包或旧修订的成功移作本版本证据。

浏览器证据限于自动化Chromium/WebKit与CSS zoom；后者不证明原生浏览器缩放，WebKit不冒充完整Safari。触屏仿真、DOM/IME测试和合成请求不外推真实设备、系统剪贴板、读屏语音或后端权限写入；不安排人工接手验收。
