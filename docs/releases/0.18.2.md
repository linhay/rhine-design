# Web 0.18.2

## 组件修复

- Dialog 的底部操作区在打开时增删，正文控件继续保留节点、草稿和焦点。重置操作如果会移除自身，应先把焦点交给仍存在的控件。 [#268](https://github.com/linhay/rhine-design/issues/268)
- Upload 使用已有 `hint` 属性显示宿主说明，省略时隐藏。宿主可以用 `hint` 说明附件何时随表单提交。 [#236](https://github.com/linhay/rhine-design/issues/236)

## 展台与配方

新增分客户端的配置模板、通栏身份卡片与交互列表、外部应用交接和显式手工备选。 [交互选型](../INTERACTION_PATTERNS.md) · [#255](https://github.com/linhay/rhine-design/issues/255) · [#256](https://github.com/linhay/rhine-design/issues/256) · [#262](https://github.com/linhay/rhine-design/issues/262)

## 安装

```sh
npm install --save-exact @linhey/rhine-design@0.18.2
```

支持 React 19 和 Vite。浏览器验收使用 Chromium、WebKit 和 CSS 缩放。查看制品及 SHA-256 的发行记录。 [GitHub Release](https://github.com/linhay/rhine-design/releases/tag/v0.18.2) · [npm](https://www.npmjs.com/package/@linhey/rhine-design/v/0.18.2)
