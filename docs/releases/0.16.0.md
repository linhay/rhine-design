# 0.16.0 发行说明

本页记录 Web 0.16.0 的接口范围和支持边界。渠道可用性以 [GitHub Release](https://github.com/linhay/rhine-design/releases/tag/v0.16.0)、[npm 精确版本](https://www.npmjs.com/package/@linhey/rhine-design/v/0.16.0) 与 [Pages 展台](https://linhay.github.io/rhine-design/) 的实际回读为准。安装前核对版本与制品校验和；源码和展台不能代替实际安装包。

## 本版改动

- [#230](https://github.com/linhay/rhine-design/issues/230)：新增 `TagInput`。受控字符串值和编辑草稿分开，支持可配提交策略、有界标签展示、原生禁用与表单关联。输入法组合不提前提交；拒绝提案保留草稿。
- [#231](https://github.com/linhay/rhine-design/issues/231)：`Disclosure` 支持只读富摘要、受控开合和首次接受展开时懒挂载；闭合不卸载已有内容。旧字符串标题和即时挂载仍兼容。
- [#232](https://github.com/linhay/rhine-design/issues/232)：`Menu` 支持具名组、分隔、受控单选和复选以及可读禁用说明。普通动作仍关闭并归焦，长菜单按视口限高并可键盘滚动。

沿用 0.15.0 的公开能力、依赖与旧版有效调用。数据、权限、服务请求、保存和选择提案的接受仍归宿主。契约、默认值和键盘行为见[组合输入契约](../COMPOSITE_INPUTS.md)。

## 支持与验证

继续提供 React 19 的 TypeScript/TSX、CSS 和 SVG 源码，使用 Vite 与 Node 24 验证。发行门禁覆盖完整测试、类型、生产与评审构建、导出目录、包检查，以及固定包的隔离新安装、公开入口、逐文件身份与双引擎生产交互。实际制品摘要与渠道结果见 Release。

浏览器范围为 Chromium/WebKit 自动化和 CSS zoom，组合输入与粘贴以合成事件分证。没有覆盖完整 Safari、原生网页缩放、系统输入法、系统剪贴板、读屏语音或真实消费项目。0.15.0 的 tag 和发行包不原位替换。
