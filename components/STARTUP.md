# Rhine Design 启动编排 · 三角构架归位

这是[莱茵设计](../README.md)的可复用启动编排模式，独立演示入口为`http://127.0.0.1:18309/#startup`。宿主决定是否采用、字标和后续页面内容。

2026-10-22，设计候选，已在 `/#startup` 实现。用户要求启动动画建立莱茵风格记忆：暖白、苔绿、三角几何、细线定位与克制的工程秩序。品牌为原创 Rhine Design，沿用已定稿 V3 母版；不引入其他作品标志或新动画库。

## 分镜与参数

| 时间（原速） | 画面 | 目的 |
| --- | --- | --- |
| 0–320ms | 三角定位线绘出，三角中心保持固定 | 建立构架，保留大面积留白 |
| 180–1060ms | 左、右、底三块先旋转压缩，再展开归位，错开80ms | 用同一方向语法形成辨识度；单块720ms、最远18px |
| 1060–1340ms | 橙色定位点出现，辅助线退去 | 用短暂信号强调几何闭合，不表示业务成功 |
| 1080–1320ms | Rhine Design字标整体淡入 | 不拆字、不缩放、不模糊 |
| 1320–1600ms | 静态品牌留白 | 展台完整分镜观察区间，不是App最低等待时间 |
| 模拟就绪后 | 同一Logo用560ms收拢至88px并上移16px，字标上移84px；登录内容420ms淡入 | 保持中轴与品牌连续，操作立即可用，不保留透明遮挡层 |

启动是品牌专属配方：允许标志18px位移与720ms旋转展开，明确区别于通用Logo的240ms/3px入场。启动分镜与品牌演示卡共用 `preview/brand-assembly.css` 配方，覆盖仅匹配展台 `.ds-brand-assembly`；普通Logo、菜单、文字和业务组件保持原规则。使用现有standard曲线，无回弹、整体转圈、扫光、伪进度、音效或装饰循环。

旋转变形是用户2026-10-22追加的明确方向：左块−120°、右块+120°、底块+60°；每块围绕自身中心从横向压缩0.22倍展开至1倍，最后transform为单位矩阵。变形只用于中间帧，不修改SVG路径；品牌卡总时长880ms，启动版延后180ms开始。最终轮廓、朝向和中心均回到V3母版。

用户指出直接切换到左对齐大标题登录页过于生硬。修订后保留同一Logo DOM与同一字标，登录页沿原中轴构图，标题降至section层级；标志外层做560ms、`cubic-bezier(.22,1,.36,1)`收拢，内部三块可继续完成归位。舞台最小高度540px，普通就绪不产生高度跳变。文字不缩放；内容整体420ms、最多3px淡入，键盘聚焦内容时直接清晰呈现。1.6秒为品牌分镜，560ms为并行呈现可用登录内容时的视觉衔接，不额外阻塞操作。

## 播放与真实状态

- 初始为静态封面，用户主动播放；重播仅重建演示画面，控制按钮焦点保持。复位/切换场景/卸载取消旧计时。4倍慢放把整个合成分镜（含模拟就绪）放慢，便于审阅，不对应真实网络耗时。
- 正常场景在1600ms模拟就绪；慢启动不自动就绪，可点击「模拟就绪」；失败在1600ms显示可读错误，无自动重试。可随时模拟就绪中断编排，以检查早到结果。
- 减少动态（系统、全局或此例）直接呈现静态品牌；正常合成场景立即进入登录示例，慢启动仍等待明确就绪，失败仍显示错误。中途开启也立即取消视觉编排和对应演示计时。
- 宿主以真实初始化状态驱动：就绪即进入目标页面，错误即显示原因和恢复操作，不等待动画结束。慢启动不循环品牌，不用橙点表示连接成功。窗口恢复、Tab切换、普通重渲染不重播；最多冷启动一次。
- 展台只演示登录落点；登录按钮可鼠标/键盘激活，只显示本地演示说明，不执行登录、恢复会话、请求或写配置。正式App接入、原生冷启动白屏/窗口合成效果尚未验证。

## 验收

检查三块SVG引用同一母版、中心不漂移；原速/慢放真实中间帧；快速重播、复位后无旧结果；失败与等待可区分；系统/手动减少动态；400/520/880px、200%缩放；键盘控制焦点与屏幕阅读状态。待用户评审后再按授权迁移App。
